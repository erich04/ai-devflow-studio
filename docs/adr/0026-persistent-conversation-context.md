# ADR 0026：本地会话事实、派生摘要与上下文预算

状态：已接受用于 Memory P2 本地候选，2026-10-04。验证与发布状态见路线图和收尾记录；不代表完整 V3.x Agent 循环已经交付。

## 决定

复用 `workbench_conversations` 的本地 SQLite JSON 与乐观版本事务。旧会话缺新增字段时按空账本处理，无需改变旧记录的解析或迁移版本。数据不加入 LocalExecutionState、团队同步、候选记忆或 Gate 证据。

- 原消息保留原 ID、正文、角色和时间；回答状态与已保存提案链接可以更新。Main 存储边界禁止用摘要替换或删除原文。既有推理展示记录不进入本契约的来源、摘要、续读或提示。
- 工具先持久化 `tool_request`，再追加以 requestId 配对的 `tool_result`；同 ID 的一致重放幂等，冲突重放或孤立结果被拒绝。工具原始返回先脱敏再保存，提示中的占位与裁切不改变该记录。恢复将缺结果的请求标为 interrupted，不自动重新调用工具或模型。
- 压缩始终从原消息构建 `extractive-v1` 摘要，保留可观察的问题回答状态和已保存草稿链接；保存不意味着批准。每个边界记录覆盖消息/工具 ID、来源 SHA-256、前一边界 ID、算法版本、生成时间。有相同来源的有效摘要可复用；损坏的派生摘要重新从原文生成并追加回执。
- 摘要事实体有 3,000 字符选择预算，每条摘录最多 240 字符。优先未回答问题、已保存提案、最初请求和较新消息。省略数和摘录截断均显式表示；`conversation_read` 只能分页读取当前会话的原文/事件或其索引，拒绝选择其他会话及隐藏推理。
- 写入压缩回执失败时不发出本次模型请求；原文保持可重试。取消不删除已产生用量和工具事实，显式 retry 不重复用户消息。重启不会自动付费请求，也不会发布草稿、接受变更或推进工作流。
- 每个宿主步骤重读当前需求、L0 与作用域内有效记忆。摘要仅为低信任历史，不能覆盖最新用户输入、批准材料、系统能力或 Gate。Direct 与临时目录中的 OpenCode 讨论栏都由宿主附上项目 L0；编码/阶段 OpenCode 沿 ADR 0025 自行加载项目说明。

## 预算与边界

共享 `PromptSection` 按 system、instructions、current、history、summary、memory、tools 等章节度量；保存估算器版本、Token、UTF-8 字节和字符数，不保存账单推断。DeepSeek 估算 ASCII/4 + 非 ASCII×1.5，OpenAI 为 ASCII/4 + 非 ASCII×2，未知提供方用 ASCII/3 + 非 ASCII×2，并为每个章节预留 8 Token。它们是可复现的保守启发式，不是精确 tokenizer 或提供方窗口承诺。

Native 默认 24,000 估算 Token，保留 30,000 user 字符及全提示 96,000 字节/40,000 字符保护；repair 在 Token 超限时同样缩小失败位置窗口。Chat 上限 48,000 估算 Token，全提示 96,000 字节/40,000 字符，保留原有 30,000 字符压缩触发与 32,000 user 字符保护。阶段输入默认 48,000 估算 Token，并保留其输入字节上限。

先移除可选记忆，再降级旧工具结果，再对旧历史生成摘要。必要时继续已有的有界截断，并明确告知；不可缩减的当前请求、关键批准正文或权限超限则发送前拒绝。提供方返回的实际 Token/费用继续走原记账链，不用上下文估算替代。

Native repair 的公开结构化 analysis / initial summary 保存在 Coding Run 轨迹，绑定成功调用和精确 Change Set；旧记录缺失时省略。它不是隐藏推理或可执行权限。

## 明确不包含

不新增常驻记忆；L0 仍由 ADR 0025 管理。不启用收费 LLM 摘要，不实现 Native 通用多轮 Agent、会话分叉/回退、协调器记忆消费者或自动恢复执行。OpenCode 内部模型循环、上下文压缩和已发送材料仍由其执行器负责；本账本覆盖宿主可观察的提交和工具边界。
