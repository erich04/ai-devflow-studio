# ADR 0029：Native Coding v3 的多轮执行与修订验证

日期：2026-10-11。状态：已实施，完整发布仍受[验收记录](../plans/native-coding-harness-v3-implementation.md)约束。

本决策针对[定稿方案](../plans/native-coding-harness-v3-20261011.md)。它替代 ADR 0015 对新 Native 运行“固定调查、一次生成、至多一次修复”的限制，以及该版本失败后只能新建 Run 的适用范围。既有 Native v1/v2、OpenCode、工作流 Gate 和团队审批契约不追溯改写。

## 决策

Native v3 是 DevFlow 自己管理的持续编码会话。模型每轮选择原生工具，宿主执行工具并将真实结果送回；模型可以重新检索、读取新文件、编辑、执行测试、澄清需求和委派任务。普通回答不构成完成。模型调用 `propose_changeset` 后，宿主根据真实文件冻结修订，交给人审查。

编码执行器描述符版本为 3；中途问答和控制命令使用 Harness protocol 2；私有会话和文件清单分别有自己的 schemaVersion。请求仍通过既有工作流入口绑定项目、Run、节点、策略与预算。

## 四种内容身份

| 身份 | 谁写入 | 用途 |
| --- | --- | --- |
| B：输入清单及内容 blob | 宿主建立后不可变 | 保留基线与用户原有改动 |
| C：私有候选仓库 | Native 受授权工具、已批准命令 | 多轮试错，拥有独立 Git 元数据 |
| D：交付工作树 | 宿主在最终批准后按事务应用 | 连接工作流与既有 GitHub 交付 |
| V：独立验证仓库 | 宿主从冻结修订建立；测试命令执行 | 独立准备依赖并验证精确内容 |

冻结修订绑定基线、目标文件清单、实际文件操作、目标版本、策略版本、测试与依赖计划。重复修订 ID 只能恢复同一份对象，不能覆盖。D 的应用有预写日志；失败时只恢复能证明属于该事务的字节，外部漂移进入冲突。测试退出 0 但修改源码仍属无效证据。

## 权威、预算与等待

主进程保留工作流、凭据、预算和最终验证权威。初始执行授权覆盖候选目录与已展示的保存测试；网络、新命令、MCP 等额外操作按请求展示给人。只读子任务不能取得编辑权，编码子任务有独立 C 和明确路径范围；父任务串行三方合入子修订。

模型请求、压缩及子任务共用真实模型调用账本。根与子额度在 API 事务中计算，Postgres 同项目准入锁阻止并发超领。根任务另以 CAS 分配共享轮次，以所有执行单元活动区间的并集累计时长。自动批次仅是调度边界，不是固定“只做 12 轮”的能力限制。

等待问题、权限和持久暂停不扣活动时长；仍在工作的子任务或命令继续计时。依赖准备、测试、模型请求、授权有效期各自管理。超时和取消停止真实进程树；逻辑租约过期不等于旧进程已经停止。

模型交付未知时保留操作身份和费用占用，禁止自动重发。用户可以明确接受重复计费风险后授权新 attempt，旧记录不会消失。文件、子合入、MCP、网络和命令用持久收据恢复；不凭一条日志推断成功。

## 历史、上下文与恢复

SQLite 保存版本化会话引用，大内容位于 `devflow.sqlite.contents`；候选内容、命令收据、修订与应用日志位于 `native-coding-harness`。多窗口控制经过版本检查与单任务队列，晚到的模型回复只能补记实际用量，不能推进被撤销的执行。

历史压缩保留完整原稿及可回读引用，用户原话和问题答案独立保留，不依赖模型摘要记住约束。UI 将问答、权限与最终审查分开，大结果和改动可以分页读全文。读取历史不需要当前模型或执行器仍然配置为 v3。

默认不自动删除日志。只有终态、没有存活写者且全部费用已经确认的根任务，才允许清理可重建的候选/验证副本；先保存候选内容清单，再删除副本。SQLite、原始对话、blob、修订与事务证据保留。备份必须包含 SQLite 及内容目录，不能仅复制数据库。

## 执行环境

`trusted_local` 使用当前 OS 用户权限，独立目录不是 OS 沙箱。`container` 使用固定镜像 digest、独立绑定目录、只读根文件系统和显式网络模式；镜像或 Docker 不可用就失败，不回退本机。平台可用性以实际平台验证为准。

## 发布条件

确定性测试、真实 Electron UI、真实 Postgres、实际容器、跨平台恢复演练与至少 30 项真实任务对照分别记录。模拟模型端点只能证明集成，不能证明模型能力收益。真实模型费用必须取得项目、模型与总上限授权；在真实任务对照与平台证据完成前不宣称完整发布已通过。
