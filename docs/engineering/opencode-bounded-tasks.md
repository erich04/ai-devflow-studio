# OpenCode 编码中的有界子任务

适用于保存了 Provider 绑定、通过 DevFlow 预算代理执行的 OpenCode 编码运行。基于 #243 的问答闭环，契约核对版本为 OpenCode 1.18.15。环境变量兼容入口、工作台对话和只读阶段不开放子任务。

## 用户流程与限制

执行授权后，模型可以将一个具体工作交给 `devflow-worker`。子任务与父任务使用同一个受管工作树、同一个模型和同一次运行的预算。子任务提问使用现有问答面板；命令仍需经过宿主策略和工具审批。回答问题不批准命令，批准子任务命令也不批准最终变更。

第一版采用串行执行：最多一层、同时一个子任务；父任务在等待子任务时不能执行其他工具。整次运行最多 4 次委派（包括续接）、24 次工具调用、32 次模型参数调用和 15 分钟活动执行时间。等待用户问题/审批时暂停活动时钟，问题仍有独立的 30 分钟有效期。工具/模型次数限制由受信插件在调用前执行，宿主另从父子历史核对工具总数；预算代理对每次实际模型请求独立预留和结算，预算限制不因拆分子任务而重置。

只接受纯文本子任务提示，禁用 `@` 文件/agent 注入、`command`、后台任务和嵌套任务。父任务可用 `task_id` 续接本次运行内已完成的子任务；其他运行、工作区、父会话或权限不一致的 ID 均拒绝。子任务总数和续接次数一起受限。

## 为什么需要显式建子会话

上游 [task 实现](https://github.com/anomalyco/opencode/blob/d7b115f623760e68a4749d16508a9eca350f246f/packages/opencode/src/tool/task.ts) 在请求 `task` 权限后创建/续接会话；[权限继承](https://github.com/anomalyco/opencode/blob/d7b115f623760e68a4749d16508a9eca350f246f/packages/opencode/src/agent/subagent-permissions.ts) 只保留父会话的 deny 和外部目录规则。直接打开 task 会让 DevFlow 的 `* deny` 被继承，而工作树工具的 allow 不被继承。另外，原生 `task_id` 不校验 DevFlow 的运行归属。

本实现保留原生 task 的调度、等待和取消机制。一个随桌面代码发布的薄插件在调用前先创建子会话，写入完整的最小权限，再将该 ID 交给原生 task。插件位于进程管理器的私有临时目录，以 0600 权限写入并随进程清理；不会写入用户仓库或加载仓库插件。

父会话的 task 始终为 ask。宿主只有在确认对应 call ID 已有显式创建的、同一运行/工作区/父会话/权限的子会话后才单次放行。插件未加载、协议变化或归属无法确认时停止，不退回无约束委派。每次委派保留父子会话 ID 的审计记录。

编码任务使用独立 HOME 和 XDG 配置目录，关闭项目 OpenCode 配置、个人插件及后台子任务，固定父子模型；仍读取受管仓库中的 AGENTS.md。仓库自己的 OpenCode agents、MCP 配置、插件和个人工具配置不参与这个编码进程。受批命令仍从 PATH 查找本地工具；有个人 HOME 配置依赖的命令需在本次受管环境中验证。

OpenCode 1.18.15 在启用本地插件时仍会等待它自己的 plugin SDK 依赖初始化。新的私有任务进程最多等待 60 秒就绪，其他进程保持 30 秒；超时会关闭进程和临时目录，不进行模型调用。该检查使用整个剩余窗口，避免每秒取消请求而反复打断初始化。

## 收尾与证据

宿主轮询时先校验父子关系，然后发现其权限和问题，审批/回答前再次核对。父请求返回不等于子任务结束；全部受管会话 idle 后，先关闭新任务准入并确认停止，再采集真实 Git diff。独立标准测试、最终变更验收继续由原有运行时处理。

取消先在父会话记录停止标记，再停止父任务及所有已核对子任务，清理残留审批和问题，并再次枚举以处理取消期间刚创建的子会话。未知会话不接管，失去子会话或清理失败不冒充成功。应用退出由进程管理器关闭整个受管进程组；重启不恢复旧子任务和旧问题。

模型费用使用已有治理代理的真实请求 ID，父子请求归于同一 Coding Run operation，不再把 OpenCode 的父子 cost 摘要相加。取消时尚无完整 usage 的请求仍按未知记录，不假设为零。

## 检查入口

```sh
corepack pnpm test:opencode-task-contract
corepack pnpm test:opencode-task-electron
```

契约脚本使用真实 OpenCode、私有临时仓库和本地合成模型，检查权限继承、子问题、工作树写入、共享模型计量、子调用被预算拦截、取消清理及迟到回答。Electron 脚本增加主进程/SQLite/表单、子命令审批、标准测试、最终验收、窗口刷新和重启失效。两者不需要真实服务商密钥；它们验证协议与宿主集成，不代表真实模型质量评估已完成。

升级 OpenCode 后必须重跑契约与 Electron 检查，尤其是插件 hook、子会话 metadata、权限继承和取消协议。真实模型验收、受控公开文档查询及 Native v3 全量对比仍是独立工作。
