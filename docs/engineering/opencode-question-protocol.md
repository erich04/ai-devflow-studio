# OpenCode 编码问题与回答

本实现完成 #237 的问答部分，基于 #241 的命令授权绑定。核对版本为本机 OpenCode 1.18.15；升级后需要重跑本文契约检查。子任务接入与额外限制见 [有界子任务说明](opencode-bounded-tasks.md)；公开文档查询仍未开放。

## 用户流程

编码过程中，OpenCode 可暂停并提出一组问题。任务面板显示“等待你补充需求”，支持单选、多选、自定义答案及跳过全部问题。默认没有预选答案，必须显式完成每道题才能提交。

回答仅补充业务需求。后续命令仍走原工具审批；编码结束后仍执行宿主标准测试，并等待独立的最终变更验收。问题和回执存于本地，不进入团队同步的原始数据。

## 协议与归属

- `opencode-process.ts` 将 `default` 与 `coding` 分成同项目内的两个进程槽位。仅编码槽位设置 `OPENCODE_ENABLE_QUESTION_TOOL=true`，有效环境参与配置指纹；默认槽位始终关闭。
- 编码会话规则明确 allow `question`，只读阶段仍 deny。外部目录和通用网络命令仍拒绝；task 仅在受管编码进程按额外规则开放。
- `GET /question?directory=...` 的结果经过结构校验，只接收当前父会话或已核对运行/工作区归属的子会话的问题；一次运行同时出现多个待回答请求时停止处理。问题记录保留实际发问会话 ID，回答前再次核对归属。
- 问题绑定 Coding Run、项目、受管工作区、会话、内容 SHA-256 修订号和到期时间。主进程额外绑定当前配对身份和执行配置。
- 渲染进程仅提交 Coding Run ID、问题 ID、修订号和回答。操作者由主进程根据当前配对确定，不能由渲染进程指定；回答必须按原问题顺序排列，满足原题的单选、多选、自定义约束。
- 提交前重新读取 OpenCode 原问题，核对内容摘要、原进程存活、工作区摘要、Git 边界和执行上下文，再向 `/question/:id/reply` 提交 `{ answers: string[][] }`，或向 `/question/:id/reject` 提交空对象。

一次最多 8 道问题、每题 16 个选项；单项回答最多 4,000 字符，总回答 JSON 不超过 32,000 字符。显示前脱敏；选项标签若需脱敏，拒绝展示可提交表单，避免展示值与实际答案产生歧义。

## 幂等、恢复与停止

`pending → sending → answered / dismissed` 表示正常投递过程。SQLite 的条件写入先认领发送权，收到 OpenCode 明确确认后，先落盘回执再等待后续模型结果。重复请求返回已有状态，不再次投递；已结束问题的最近 24 份摘要回执用于后续重放核对。DevFlow 问答审计事件保留操作者和回答摘要，不额外保存答案正文；OpenCode 原会话仍会使用实际答案继续执行。

其他状态为 `expired`、`invalidated`、`delivery_unknown`。网络错误后的只读查询不能证明特定回答是否被接收，所以不自动重发；尝试停止原会话并保留工作区。清理失败时保留活动运行和错误记录，允许用户重试停止，不宣称已经结束。

问题默认最多等待 30 分钟；等待期间暂停引擎活动执行时钟。过期后禁止回答并清理原会话。取消先在本地认领停止状态，迟到的回答或确认不能恢复执行。窗口刷新继续使用同一主进程和已保存问题；应用重启不能恢复旧 OpenCode 会话，因此旧问题失效，工作区保留供核对。

真实 OpenCode 1.18.15 的 `/session/:id/abort` 可能仍保留待回答问题。本实现先 abort，再 reject 残留问题，最后再次 abort 并确认清理完成；已经消失的问题返回 404 可视为清理完成。原服务进程退出后，不向可能复用该端口的新进程发送回答。

## 可复现检查

```sh
corepack pnpm test:opencode-question-contract
corepack pnpm test:opencode-question-electron
```

第一个命令启动真实本地 OpenCode 与隔离的合成模型服务，验证问题协议、顺序答案、自定义、多选、拒绝、重复回复 404、取消和进程/会话隔离。第二个包含上述检查，并通过真实 Electron 主进程、preload IPC、SQLite 和问题表单验证回答后修改工作树、执行标准测试、停在最终验收、刷新续答及重启失效。

两者使用临时项目、隔离 HOME 和合成凭据；不会读取用户模型密钥，也不会调用付费模型。Electron 测试仅为合成服务关闭未知价格预算检查，并使用测试内存加密适配；这不改变产品的预算或凭据设置。截图写入忽略目录 `output/playwright/opencode-question/`。

单元测试另覆盖：伪造操作者、旧修订号、问题内容/工作区变化、进程退出、超时、发送结果不明、清理失败、并发重复回复、取消与回执竞争。实际验收记录见 [本次交付计划](../plans/issue-237-question-20261016.md)。
