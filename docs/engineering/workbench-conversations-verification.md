覆盖了以下边界：切卡片不改变会话范围、多个会话并行隔离、跨项目隔离、私有草稿不共享、

可机器读取的本机证据在 `out/workbench-conversation-qa/report.json`、
`delivery-report.json` 和 `live-report.json`。最后一份记录真实 DeepSeek 返回、来源、按钮和用量。
当前测试没有修改用户原始演练数据，也没有向真实 GitHub 仓库推送或合并。

真实模型联调同时验证并修复了一个兼容问题：合法 JSON 的字符串内可以含 Markdown 代码
示例，旧解析器会误拒绝这类回答。现在仍要求单个 JSON 对象，只接受完整的可选外层 JSON
代码围栏；外层散文、额外对象和非法嵌套仍会拒绝。回归用例和 DeepSeek 的实际代码示例
回答均通过。联调启动器移除了 Playwright 默认模拟钥匙串参数，以使用正常系统钥匙串；
生产凭据逻辑未修改，联调限制最多 4 次 HTTP 请求。

这份记录是本次功能验收，不替代仓库的正式版本发布签名、跨操作系统实机验收或付费
