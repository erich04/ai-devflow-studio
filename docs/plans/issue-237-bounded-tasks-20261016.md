## 本增量

- 只在保存 Provider、受治理代理保护的编码入口启用一层串行 task；默认最多 4 次委派/续接、24 次工具调用、32 次模型参数调用，父子共享限制。
- 原生 OpenCode task 仍负责执行；私有插件只进行参数、归属、权限、并发和计数检查。失去插件或协议不匹配时拒绝准入。
- 子问题和子命令审批进入同一 Coding Run；审批和回答前复核子会话及工作区，最终仍需标准测试和变更验收。
- 完成和取消都关闭准入、停止父子会话、清理残留问题/权限，确认 idle 后采集结果；费用沿用同一 operation 的真实调用账本。
- 说明和可复现入口见 [有界子任务协议](../engineering/opencode-bounded-tasks.md)。
