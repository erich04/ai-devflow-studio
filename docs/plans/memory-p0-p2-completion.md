## 实现契约

- 保留历史 8 KiB 记忆解析与修订能力。共享函数计算 UTF-8 字节数和每个入口的可容纳状态；界面解释编码 3,800、阶段 2,800、讨论 1,800 字节的实际单条阈值。满足大小仍需通过范围、生命周期、相关度和剩余预算检查。
- 讨论栏每个宿主模型步骤重新召回可选记忆，删除/过期在下一步骤生效；召回失败继续无记忆。恢复不使用持久记忆正文快照。L0 沿用 ADR 0025；Direct 与临时目录中的 OpenCode 讨论栏由宿主附上当前项目说明，编码/阶段 OpenCode 在受管项目中自行加载。
- Native repair 只保存模型结构化公开结果中的 analysis / initial summary，绑定成功调用及精确 Change Set 的持久轨迹；旧记录缺摘要时可继续。摘要不授权，不保存隐藏推理。
- 在现有本地会话 JSON 中追加版本化会话账本和派生压缩边界；不另建常驻记忆或团队同步。原消息完整保留，工具请求先持久化、结果以配对 ID 追加，缺失结果标为中断且不自动重做。重试是明确操作，只读工具可重新查询；任何恢复均不发布草稿或推进 Gate。
- 确定性摘要直接从原始消息重建，记录覆盖消息 ID、源摘要、算法版本和前一边界。问题回答与已保存草稿保留为有来源的状态，不能推断批准。摘要有界，未附带内容明确标记，可通过本会话只读续读工具恢复。摘要不是原始事实的替代品；重复构建幂等，来源改变使派生摘要失效。压缩写入失败阻止本次模型请求，保留原始数据供显式重试。
- 共享 PromptSection 度量按提供方使用明确版本的保守 Token 估算，并同时保留字符和 UTF-8 硬限制；该估算不是账单 Token 或精确 tokenizer。可选背景先移除，工具结果降级，再压缩旧历史；当前用户请求、批准材料和系统权限不可被摘要覆盖。超出不可缩减容量时在发送前拒绝。
- 不实现收费 LLM 摘要；确定性路径为默认且完整的恢复路径。OpenCode 内部会话仍由其执行器负责，本地账本覆盖 DevFlow 提交的消息和本地工具边界，不声称控制 OpenCode 内部压缩。
