# v0.2 最终验证计划

本文为 v0.2 历史计划；以下任务与状态保留当时含义，不构成当前执行指令或当前验收结论。

<a id="goal"></a>

## 目标

解决真实 Electron 冒烟测试的间歇失败，证明完整验证命令稳定，使已实现的 v0.2 Final 范围可确认发布。

v0.2 本计划在本机 macOS 验证。Windows 兼容是 v0.3 验收约束，但 v0.2 修复也不能引入仅适用于 macOS 的路径、shell 或选择器假设。

<a id="code-facts-checked"></a>

## 已检查的代码事实

- `packages/shared/src/domain.ts` 已定义 `DataOrigin`、`LocalSettings`，以及包含 `settings` 和 `mcpServers` 的 `LocalExecutionState`。
- `apps/desktop/electron/local-store.ts` 已使用 SQLite schema `2`，持久化本地设置和 MCP 服务器，并加载完整本地执行快照。
- `apps/desktop/electron/main.ts` 已提供创建/保存 Run、保存 Agent Event、设置和 MCP、本地测试执行的 IPC 处理器。
- `apps/desktop/src/App.tsx` 已分离 `seed` 和 `local` 状态，保存新 Run、Gate 批准事件、主题/MCP，并接入搜索过滤。
- `scripts/electron-smoke.mjs` 已覆盖真实 Electron preload 安全、本地项目选择、主题/MCP 持久化、创建 Run、批准 Gate、本地测试、阻断命令和重启保留。

<a id="current-conflict"></a>

## 当时的冲突

路线图仍将 v0.2 Final 写作计划中，但代码已经实现。剩余缺口是验证稳定性。

最近一次完整 `corepack pnpm verify` 在 `scripts/electron-smoke.mjs` 点击“通过 Gate”时失败：脚本选择 `flow-node-n-design-gate` 后按钮仍禁用。单独重跑 `corepack pnpm test:electron-smoke` 通过，说明需要检查不稳定的选择/等待路径，而不是认定产品缺少能力。

<a id="tasks"></a>

## 任务

<a id="task-1-stabilize-new-run-selection-in-electron-smoke"></a>

### 任务 1：稳定 Electron 冒烟中的新 Run 选择

修改文件：`scripts/electron-smoke.mjs`。

1. 点击画布节点前，等待新 Run 行确实选中。
2. 点击“通过 Gate”前断言 Inspector 正显示预期节点标题。
3. React Flow 选择发生竞态时，优先等待稳定状态，不强制点击画布。
4. 不依赖 macOS 专用路径、`/tmp`、`bash`/`zsh` 或 POSIX 路径分隔符。

验证：

```bash
corepack pnpm test:electron-smoke
```

预期通过。

<a id="task-2-prove-full-verification-stability"></a>

### 任务 2：证明完整验证稳定

除非任务 1 发现生产代码竞态，否则不修改生产文件。

1. 运行完整验证命令。
2. 通过后再运行一次，检查是否存在冒烟偶发失败。
3. 若失败，记录精确选择器，修复等待路径后重试。

```bash
corepack pnpm verify
corepack pnpm verify
```

预期两次均通过。

<a id="task-3-mark-v02-complete-after-stable-verification"></a>

修改文件：`docs/roadmap.md`。

2. 将 v0.2 最终验证补丁摘要移到已完成里程碑。
3. 保持 v0.3 为下一个活跃计划里程碑。
