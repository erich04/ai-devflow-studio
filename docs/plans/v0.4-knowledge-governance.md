# DevFlow Studio v0.4：知识治理

<a id="summary"></a>

## 摘要

v0.4 将已有样例驱动的 Knowledge 页面扩展为面向规范的知识治理功能。该历史阶段尚不实现真实 Agent 强制执行，而是验证团队知识可保留在 Git 管理的 Markdown 中，由 DevFlow 建索引、可视化，并将工作流证据关联到规范。

<a id="scope"></a>

## 范围

- 添加类型化的 Knowledge Source File 和 Knowledge Document 模型。
- 将 Markdown frontmatter 索引为治理文档、图实体和标签关系。
- 为 Run、Artifact、Test Evidence 和 Gate 决定增加轻量知识引用。
- 在桌面 Inspector 中增加选中节点的治理检查。
- Knowledge 页面展示 Git Markdown 索引、图谱和当前 Run 引用。
- 在 `docs/knowledge/` 添加代表性 Markdown 文件。

<a id="out-of-scope"></a>

## 范围外

- 不执行真实 LLM 或 Agent 强制约束。
- 不提供 Markdown 编辑写入器或仓库文件监听。
- 不做向量搜索、嵌入、远程知识 API 或 Postgres 持久化。
- 不实现 HoneyAI 适配器。

<a id="implementation-notes"></a>

## 实现说明

- Markdown 保持事实源地位。
- 首版运行时索引使用样例，但与 `docs/knowledge/` 的真实 Git 路径对应。
- 知识逻辑作为纯函数放在 `packages/shared/src/knowledge.ts`。
- 桌面界面使用共享函数，不在 React 组件内嵌匹配规则。
- v0.5 可复用 `KnowledgeGovernanceCheck` 结构，在 Gate 批准前阻断或警告。

<a id="test-plan"></a>

## 测试计划

- 单元测试覆盖 Markdown 索引、图谱生成、引用创建和治理检查。
- React 测试覆盖 Inspector 检查及知识文档/引用展示。
- 浏览器端到端覆盖知识治理导航和规范搜索。
- 完整验证：

```bash
corepack pnpm typecheck
corepack pnpm test
corepack pnpm test:e2e
corepack pnpm test:electron-smoke
corepack pnpm build
corepack pnpm verify
```

<a id="completion-criteria"></a>

## 完成标准

- 审阅者能看到选中 Gate/节点应参考的规范。
- Knowledge 页面可查看 Markdown 源路径和标签。
- 存在证据时，当前 Run 引用至少包含 Run、Artifact、Gate 决定和 Test Evidence 目标类型。
- v0.2/v0.3 原有本地执行和团队同步测试继续通过。
