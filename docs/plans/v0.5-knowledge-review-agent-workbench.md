# DevFlow Studio v0.5：知识审查 Agent 工作台

<a id="summary"></a>

## 摘要

v0.5 引入首个真实 Agent 运行时：知识审查 Agent。它把原始 Run 请求和 Gate 关联产物的完整正文作为审查对象，以知识检索引用作为审查标准，测试证据作为补充，写入 Agent Review 产物、Agent Event、Agent Trace、Gate Advisory 及 token/费用用量。

该历史里程碑专注做好一种 Agent，不包含编码 Agent、多 Agent 编排、真实 MCP 执行、仓库编辑、向量 RAG 或自动修复。

<a id="scope"></a>

## 范围

- 共享知识审查核心，支持确定性模拟服务商及 OpenAI 兼容服务商。
- Electron 本地运行时以 SQLite 保存审查、轨迹、用量、产物和事件。
- API 后端复用同一核心及 Postgres 仓库边界。
- 服务商凭据元数据 API 永不返回明文密钥。
- 桌面 Agent 工作台与 Inspector 入口。
- Web 管理台展示，并通过服务端动作触发后端审查。
- Gate Advisory 默认仅警告。
- Electron 仅向团队 API 同步脱敏摘要。

<a id="implementation-progress"></a>

## 实现进度

- 共享领域类型与核心已实现于 `packages/shared/src/agent-review.ts`。
- Electron IPC、preload API、本地表和主进程运行时已实现。
- 桌面界面包含 `Agents` 导航和 Inspector `Agent Review` 动作。
- API 支持列出/保存服务商、执行后端知识审查、列出审查、同步脱敏本地摘要。
- Seed 和 Postgres 仓库保存服务商元数据、审查结果、轨迹、用量、产物和事件。
- Web 管理台可读取审查，并通过服务端动作触发后端模拟服务商审查。
- 测试覆盖共享核心、脱敏、SQLite、IPC 契约、API 路由、仓库边界、Web 客户端/页面、浏览器端到端及 Electron 冒烟。

<a id="current-review-contract"></a>

## 审查契约

- 需求确认 Gate：只审查精确关联的一份完整澄清产物。
- 方案 Gate：审查完整已批准澄清产物，以及关联当前 Gate 的完整设计产物。
- 其他受支持 Gate：审查精确关联当前 Gate 的完整产物。
- 知识、策略和 Gate 元数据属于标准与依据；摘要或知识不能替代审查对象。
- 提示词分为 `REVIEW_SUBJECT`、`REVIEW_CRITERIA`、`CONTEXT_APPLICABILITY`、`REVIEW_OUTPUT`。
- 按阶段与节点种类投影上下文。省略不适用或可选空字段，明确显示策略要求但缺失的字段；模拟与付费服务商使用相同契约。
- 词面匹配、语义相关性和审查用途是独立字段。旧 `score` 保持可读，但不能升级为语义相关性或证据。
- 无论模拟或付费服务商，正文均先脱敏、按确定上限裁切分块。大小不受支持或关联不完整/有歧义时，在产生服务商费用前拒绝继续。
- 审查、轨迹与报告产物记录上下文清单：精确产物 ID、内容摘要、修订时间、覆盖情况和知识标准摘要。
- Gate 执行约束重新核对清单；请求、正文、修订或关联改变后，原审查变为过期。
- 远程仅同步脱敏清单元数据和审查摘要，不发送完整审查对象或提示词。
- Inspector 区分知识/策略“引用来源”和可审计“证据”；节点矩阵和兼容规则见 `docs/engineering/workflow-context-projection.md`。

<a id="completion-criteria"></a>

## 完成标准

- 从桌面 Inspector 执行审查，在本地 SQLite 生成审查、轨迹、用量、产物和事件。
- Electron 与 API 使用相同阶段对象解析及上下文清单契约。
- 对象缺失、多份、过期、来自错误 Run/节点、为空或过大时，明确拒绝/报错，不能退而审查摘要。
- 桌面工作台显示服务商状态、审查历史、轨迹步骤、仅警告的 Gate Advisory 和费用来源。
- `/api/agent/knowledge-review` 通过同一共享核心创建团队可见审查数据。
- Web 可查看和触发后端审查。
- Electron 只同步 `RemoteAgentReviewSummary`。
- v0.5 Gate 批准仍由人控制，Agent 建议不阻断。

## 后续扩展

- 当时计划在 v0.6 增加可配置 Gate 约束策略。
