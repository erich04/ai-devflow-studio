# DevFlow Studio v0.6：OpenCode 编码适配器

<a id="summary"></a>

## 摘要

v0.6 将 DevFlow 建设为自身的编码工作台，但不重新实现 OpenCode。DevFlow 托管编码引擎、组织上下文、创建受管工作树、转交授权、归档差异/依赖准备证据，并只向团队后端同步脱敏摘要。这是历史版本范围；后续 Native 执行器另有独立计划。

<a id="implementation-progress"></a>

## 实现进度

- 技术试验完成：首版传输选用 HTTP 服务，未直接使用 ACP。
- v0.6.0 已实现：模拟编码执行框架、受管 Git 工作树、SQLite schema v4、编码面板、权限批准/拒绝、模拟 diff 产物、依赖准备证据、取消及工作树打开/删除。
- v0.6.0 加固已实现：共享开发任务资格判断、DevFlow 编码简报上下文、运行时发布器/preload 订阅、权限超时失效、模拟引擎工作树测试证据持久化。
- v0.6.1 基础已实现并测试：OpenCode HTTP 适配器封装会话创建、权限、回复、中止、发消息和取 diff。
- v0.6.1 运行时已实现：环境开关选择 `opencode-http`，托管 `opencode serve` 生命周期，转交真实会话/消息/权限、中止、脱敏差异抓取、依赖准备及手动 `corepack pnpm test:opencode-smoke` 入口。
- v0.6.1 在 macOS 使用 OpenCode `1.17.5` 和火山引擎 Ark `double/ark-code-latest` 完成真实验收：创建受管工作树、转交 `edit` 权限、通过 DevFlow Git 回退读取 diff、运行依赖准备与测试，并正常退出。原始成功输出保留为 `opencode smoke passed; changed paths: devflow-opencode-smoke.txt`（冒烟通过，变更路径为该文件）。
- v0.6.1 多步真实权限转交完成：处理 OpenCode 的 `bash -> edit -> bash -> bash` 请求，各自通过 DevFlow 批准，随后捕获 `devflow-opencode-smoke.txt` 并完成测试证据流程。
- v0.6.2 已实现：脱敏 `RemoteCodingAgentSummary` 同步端点、Electron 客户端及 Postgres `coding_agent_summaries` 读写，供团队概览使用。

<a id="future-compatibility-hardening"></a>

## 后续兼容加固

将 v0.6.1 从 macOS 手动签署提升为发布验证时，增加受管工作树路径和依赖准备的 Windows 冒烟。这是跨平台发布加固项，不阻断当时 v0.6 本地运行时里程碑。

<a id="guardrails"></a>

## 约束

- 渲染进程不能直接访问文件系统或 shell。
- 不写全局 OpenCode 认证，不使用 `--dangerously-skip-permissions`。
- 每个本地项目最多一个活跃编码 Run。
- 工作树隔离不等于沙箱。
- 权限超时默认拒绝。
- 远程变更路径必须是仓库相对路径，最多 50 项。
- 当时 diff 正文上限 50,000 字符，新增行进行密钥脱敏。后续出站扫描与完整行脱敏见独立稳定性计划，不能把这一历史规则当成最新安全边界。
