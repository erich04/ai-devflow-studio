# DevFlow Studio v0.7：可配置 Gate 约束策略

<a id="summary"></a>

## 摘要

v0.7 将仅警告的审查升级为可配置、可解释、可审计的 Gate 执行约束。开箱默认仍为 warn-only；团队必须明确应用推荐或自定义策略，才会阻断批准。本文保留历史里程碑的范围和验收结果。

<a id="scope"></a>

## 范围

- 共享策略模型、解析器、校验器、评估器和 `canApproveGateNow`。
- warn-only 默认策略和推荐约束预设。
- 知识审查输出中的 Agent Policy Findings。
- API/Postgres 策略保存、评估及 Gate override 路由。
- Web 团队台策略面板与应用推荐预设动作。
- Electron 本地策略快照、override 保存、评估 IPC 和批准写入路径约束。
- ADR 0010 及领域术语更新。

<a id="completion-criteria"></a>

## 完成标准

- 策略底线限制更弱的项目覆盖配置。
- Agent 意见永不能直接形成硬阻断。
- warn-only 默认保留人工批准。
- 推荐预设阻断确定性的缺少审查、测试、API 契约情况。
- 批准写入路径使用 `canApproveGateNow`，不能只靠渲染层按钮禁用。
- 桌面在 SQLite schema v5 保存策略快照和 override。
- Web 通过 API 应用推荐策略。

<a id="out-of-scope"></a>

## 范围外

- 自动修复或编码重试循环。
- 真实 MCP 策略执行。
- 策略签名或 KMS 快照完整性。
- Windows 策略缓存的完整 Electron 冒烟。
- 在桌面编辑团队策略。

<a id="implementation-progress"></a>

## 实现进度

- 共享核心和单元测试：已实现。
- Agent Policy Findings 及脱敏远程元数据：已实现。
- API/Postgres schema v3、策略和 override 路由：已实现。
- Web 策略面板及 API 客户端：已实现。
- Electron 策略快照/override 保存与批准写入保护：已实现。
- 2026-06-18 签署验证：`corepack pnpm typecheck`、`test`（195 项）、`test:cross-platform`、`test:e2e`（3 项浏览器测试）、`build` 均通过；完整 `corepack pnpm verify` 在已提交状态通过。`test:electron-smoke` 覆盖缓存推荐策略、直接 `approveGate` 被阻断、有效 lead override 和重启保留。`test:postgres-smoke` 在 `initdb` 创建的临时 Postgres 集群通过，覆盖策略保存/读取/评估、owner/member/利益冲突 lead 的 override 拒绝、合格 lead 接受、过期版本拒绝、概览审计与脱敏。
- v0.7.x 加固：增强桌面策略界面、批准前在线刷新、临时 override 对账。
- 具体进展：`corepack pnpm dev:electron` 明确通过应用路径启动；Inspector 显示约束状态、策略来源/版本/syncedAt、阻断原因、处理建议及已确认/临时 override；无缓存策略的团队项目返回 `blocked_policy_unavailable`，纯本地项目保留内置 warn-only 默认。
- Electron 主进程批准前尽力刷新远程策略，写入时仍执行 `canApproveGateNow`。API Run 摘要同步拒绝 `approval` 摘要，防止绕过约束。
- 桌面保存/对账 override 时先尝试团队 API：确认接受后保存为正式，网络失败保持临时，过期/无权响应记为拒绝。Inspector 区分被拒 override，直到有效 override 或新证据解决策略决定才解除阻断。
- 已新增 `docs/engineering/testing-strategy.md`、`docs/engineering/demo-and-smoke.md` 和 `CONTRIBUTING.md`，并提取 `useGateEnforcement` 与 `GateEnforcementPanel` 便于维护。
