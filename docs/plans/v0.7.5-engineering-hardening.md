# DevFlow Studio v0.7.5 工程加固签署

<a id="summary"></a>

## 摘要

v0.7.5 是 v0.7 Gate 约束的签署和加固里程碑，不新增运行时产品能力。它统一包元数据、记录 v0.7.x 加固范围、归档路线图状态，并建立 v0.8 计划入口。

签署前最后一个实现提交为 `110f472 feat: harden v0.7.5 gate enforcement workflow`（加固 Gate 约束工作流）。以下结果属于当时版本。

<a id="completed-scope"></a>

## 完成范围

- 根工作区及全部自有包的版本提升到 `0.7.5`：root、`@ai-devflow/shared`、`@ai-devflow/desktop`、`@ai-devflow/api`、`@ai-devflow/web`、`@ai-devflow/worker`。
- 路线图将“v0.7.x：约束界面与对账加固”从计划移至已完成里程碑。
- `CONTEXT.md` 增加策略感知交付、处理计划、重试尝试的领域术语。
- 添加下一里程碑 `docs/plans/v0.8-policy-aware-delivery.md`。

<a id="v07x-runtime-state"></a>

## v0.7.x 运行时状态

`110f472` 包含：

- Inspector 解释 Gate 状态、策略来源、阻断原因、处理建议和 override 状态。
- 团队项目没有权威缓存策略时返回 `blocked_policy_unavailable`。
- 批准前在线刷新策略。
- API 同步拒绝类似审批的摘要，防止约束绕过。
- 对账已确认、临时和被拒 Gate override。
- 桌面结构围绕 `useGateEnforcement` 与 `GateEnforcementPanel` 划分职责。

<a id="environment-notes"></a>

## 环境说明

- 端口 `4310`、`4311`、`5173` 占用导致失败时，应先确认并处理相关进程再重跑。端口环境故障不能算验收成功。
- 首次使用 Playwright 或 Electron 可能需要安装浏览器/运行时。
- Postgres 冒烟可用 Docker 或临时本地集群；本次使用动态端口的临时集群。
- `0.7.5` 是作品集与产品里程碑版本，不代表发布到 npm。
