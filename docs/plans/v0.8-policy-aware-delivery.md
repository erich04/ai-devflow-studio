# DevFlow Studio v0.8：感知策略的交付自动化

<a id="summary"></a>

## 摘要

v0.8 将 Gate 约束结果转为人工批准的交付动作：从策略警告/阻断生成清晰处理计划，加入编码 Agent 上下文，由审阅者决定何时重试或补证据，不自动改码或绕过 Gate。

历史里程碑直接基于 v0.7.5 已有的 Gate 约束、知识审查、本地测试证据及受管编码运行时。

<a id="key-changes"></a>

## 主要变更

- **v0.8.1 处理模型**：共享处理计划与候选类型；根据 `GateEnforcementDecision.blockingReasons`、`warningReasons`、`requiredActions`、知识治理检查、Agent Policy Findings 及测试证据生成候选。模型确定性且测试先行，单独检索命中仍不算证据。
- **v0.8.2 编码简报中的策略上下文**：简报纳入所选处理计划、相关策略原因、知识引用、已有测试证据和编码差异摘要。渲染层仍只传 ID 与用户指令，最终组装归主进程/共享运行时。候选重构点为 coding-runtime、coding-runner，以及后续 useCodingRun、CodingAgentPanel。
- **v0.8.3 人工批准重试**：Inspector/Agents 提供从处理计划启动重试的动作；不自动编码重试、不自动 override、不在受管工作树外自动修改仓库。重试持久化为可审计事件/产物，关联所处理的策略原因。
- **v0.8.4 管理摘要**：Web/API 按项目/Run 汇总警告、阻断、override、处理计划、重试次数及剩余证据缺口；不上传原始本地路径、日志、提示词或补丁。

<a id="public-interfaces--types"></a>

## 公开接口与类型

预期共享类型：`RemediationPlan`、`RemediationCandidate`、`RetryAttempt`、`PolicyAwareDeliverySummary`。

运行时边界：Electron 根据本地状态评估/生成处理计划；API/Web 消费脱敏处理与重试摘要；编码简报只通过主进程/共享组装接收处理上下文。

<a id="test-plan"></a>

## 测试计划

- 共享单元测试：缺少审查、缺少/失败测试、API 契约违规、硬阻断文案的确定性生成；只有检索引用时不能视为治理证据。
- Electron/运行时：只有人工启动重试才加入处理上下文，重试记录关联原因 ID 和已有证据。
- React/端到端：被阻 Gate 展示处理计划和重试入口，用户确认后才创建受管编码 Run，管理台显示脱敏摘要。
- 冒烟：`corepack pnpm verify`、`corepack pnpm test:electron-smoke`；API/Postgres 摘要变化时另跑 `corepack pnpm test:postgres-smoke`。

<a id="implementation-progress"></a>

## 实现进度

- v0.8.1 确定性处理模型及上述四类型完成。
- 已支持受保护 Gate 缺审查、缺少/失败测试、API 契约违规、硬阻断文案、策略不可用及 Agent 意见的处理建议。
- v0.8.2 简报整合完成：仅人工重试时加入上下文，渲染输入仍为 ID 和可编辑指令。
- v0.8.3 经主进程 IPC、startRetryAttempt、SQLite 持久化、Inspector 入口和 Agents 历史完成人工批准重试。
- v0.8.4 API 概览和 Web 团队台加入脱敏摘要。
- 发布式验证于 2026-06-19 完成，06-20 更新：`corepack pnpm verify` 通过类型、238 项 Vitest、跨平台、3 项浏览器端到端及 Electron；`corepack pnpm build` 通过 API、Worker、桌面渲染/Electron/preload、共享包和 Web；`DEVFLOW_DATABASE_URL=... corepack pnpm test:postgres-smoke` 在临时本地库通过。
- Electron 冒烟覆盖被阻 Gate、审查、处理计划、人工 Retry Coding、权限转交批准、模拟差异及测试证据归档。
- PR #3 加固 Electron 运行时触发、Web/API 测试证据摘要同步和 Postgres 冒烟 API 关闭。

<a id="assumptions"></a>

## 假设

- v0.8 不包含 HoneyAI 桥接、RAG/向量检索、真实 MCP 执行策略、免审批自动修复、Electron 打包/签名或分发。
- 先做共享处理模型，再修改编码界面。
- 仅当 v0.8.2/v0.8.3 使 App.tsx 编码路径难以维护时，再考虑提取 useCodingRun 和 CodingAgentPanel。
