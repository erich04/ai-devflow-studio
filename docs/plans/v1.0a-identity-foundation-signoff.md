# DevFlow Studio v1.0a：身份基础签署

<a id="summary"></a>

## 摘要

v1.0a 为 GitHub OAuth、桌面配对和自托管团队部署建立身份基础。此阶段不添加 OAuth 界面或令牌交换，而是使已有 API/团队模型能区分真实认证用户与演示请求头，同时保留团队台投影。

在 `devflow-v1.0-team-pilot-foundation` 分支实现至 `b92fe01` 后完成签署。本文保留当时范围与结果。

<a id="scope-completed"></a>

## 完成范围

- 新增共享身份类型 `User`、`AuthAccount`、`AuthenticatedIdentity`、`DemoSession`、`AuthenticatedSession`。
- `TeamMember` 保持界面展示投影，成员关系事实仍由 `project_members` 持有。
- 团队 schema 和演示种子新增 `auth_accounts`。
- 仓库增加身份查找：Seed 解析如 `demo:u-ling` 的演示 GitHub 账户；Postgres 按 `auth_accounts -> users -> project_members` 解析。
- 分离 API 会话语义：缺失请求头时不再默认演示，除非显式传 `allowDemoFallback: true`；认证会话要求 `x-devflow-session-source: authenticated` 和 `x-devflow-auth-account-id`。
- 增加认证远程同步请求头工具，为后续桌面配对准备。
