# DevFlow Studio v1.1：运行费用与预算保护

<a id="summary"></a>

## 摘要

v1.1 为真实编码运行增加费用保护。默认验证使用确定性、无费用模拟引擎；真实服务商生成脱敏费用摘要，团队策略要求 lead 审批时，在调用前阻断。

边界不变：DevFlow 保存和同步摘要，不上传原始提示词、本地路径、stdout/stderr、补丁或服务商秘密。本文是 v1.1 历史方案，估算及 API 不可用规则不应代替后续更严格费用契约。

<a id="delivered-scope"></a>

## 已交付范围

- 共享编码费用估算、项目运行预算策略和预算批准。
- BudgetGuardDecision 记录允许、警告、阻断或超预算批准。
- Electron 在调用编码引擎前估算，估算非零且将使用付费服务商时查询团队预算 API。
- API 端点：`GET /api/runtime/budget-policy`、`PUT /api/runtime/budget-policy`、`POST /api/runtime/budget/evaluate`、`POST /api/runtime/budget-approvals`。
- Postgres 保存预算策略、批准及脱敏费用摘要，团队汇总纳入编码费用，远程编码摘要增加费用和预算决定元数据。

<a id="non-goals"></a>

## 非目标

不根据实时 token 流自动停止服务商，不做托管账单/发票/SaaS 计量，不默认在 CI 调付费模型，不上传原始提示词/cwd/stdout/stderr/补丁，不取代明确执行的真实 OpenCode 发布冒烟。

<a id="signoff-notes"></a>

## 签署说明

- 当时模拟/本地服务商执行视为零费用；真实 OpenAI 兼容服务商未返回用量时使用确定性 token 估算。后续真实用量与估算已分开，此处保留版本历史。
- 预算在 `engine.start(...)` 前检查，超预算在 lead 批准前不消耗 token。
- 当时团队 API 不可用时，不用猜测策略阻断本地执行，而记录未应用团队预算决定；严格控制依赖 API 可用性监控。
- 真实发布冒烟须明确运行：

```bash
DEVFLOW_RUN_OPENCODE_SMOKE=1 corepack pnpm test:opencode-smoke
```
