- 验证已有未签名请求头保护及安全打包；没有已证实绕过时不重写。
- GitHub 交付留在 V1.5。
- 试点包不签名，不包含安装器、签名、公证和自动更新。
- API 知识来源及 Web/桌面写入权限归属，必须在写入路径落地前形成 ADR。

## 工作约定

- 从 V1.3 发布后的干净基线建立 `codex/v1.4-pilot-trust-boundary` 开发。
- 不暂存或编辑主工作树中用户修改的指南、研究笔记、`.zcode/`、`module.yaml` 和已有 `work/` 内容。

<a id="slice-a1--coding-runtime-paid-budget-fail-closed"></a>

## 切片 A1：编码运行时付费预算拒绝不确定请求

<a id="tracer-1-guard-dependency-missing-"></a>

### 验证路径 1：预算守卫依赖缺失 ✅

失败测试（RED）：

- 未配置预算守卫的真实付费编码引擎，在提供方初始化/调用前返回失败的 Coding Run。
- 失败持久保存为脱敏 Run/Event，不留下受管工作树。
- 模拟/无费用编码在没有守卫时仍可用。

最小实现（GREEN）：

- 用考虑费用的不可用决策，替换“守卫缺失就允许”的通用回退。
- 给出精确的不可用说明，避免将每种失败都描述为需要 lead 批准。

<a id="tracer-2-team-decision-unavailable-or-invalid-"></a>

### 验证路径 2：团队决策不可用或无效 ✅

失败测试（RED）：

- 未配对项目、超时/网络错误、401/403、5xx 和格式无效的 2xx 预算响应，均在提供方初始化/调用前阻止。

最小实现（GREEN）：

- 从 `main.ts` 提取 Electron 预算守卫，提供小型可测接口。
- 在共享决策词汇中增加 `unavailable`。
- 向运行时返回远端预算响应前进行运行时校验。

<a id="tracer-3-policy-intent-"></a>

### 验证路径 3：策略意图 ✅

失败测试（RED）：

- 缺少策略时按不可用阻止。
- 显式保存的停用策略仍是经过认证的允许决定。
- 已启用策略的允许、预警和超预算行为保持不变。

最小实现（GREEN）：

- 在共享求值器中区分策略缺失和显式停用。

<a id="tracer-4-approval-scope-"></a>

### 验证路径 4：批准作用域 ✅

失败测试（RED）：

- 项目、提供方、请求人、角色、状态、费用上限或有效期错误，均不能授权付费调用。

最小实现（GREEN）：

- 在既有字段外，将批准校验进一步绑定到项目和提供方。

<a id="a1-hard-stops"></a>

### A1 硬性停止条件

- 任何真实付费编码路径，都不能把守卫、配对、认证、网络、服务器、策略或响应校验失败转成 `blocksRun: false`。
- 拒绝决策之后，不调用 `engine.ensure` 和 `engine.start`。
- 被拒绝的尝试不得留下受管工作树。
- 模拟/无费用行为保持显式且测试通过。
- 测试不调用真实提供方。

<a id="slice-a2--knowledge-review-paid-preflight-and-audit-"></a>

## 切片 A2：知识审查付费预检与审计 ✅

- 将批准绑定到精确的项目、提供方、请求人、费用和有效期。

V1.4 编码及知识审查路径的付费运行时信任边界已完成。

<a id="verification-ladder"></a>

## 分层验证

每条验证路径：

1. 运行新增定向测试并记录预期失败。
2. 完成使测试通过的最小实现。
3. 重跑目标文件。
4. 测试通过时才重构。

完成一个切片后，运行相关扩大验证集：

- `corepack pnpm typecheck`
- `corepack pnpm test`
- `corepack pnpm test:cross-platform`
- 包输出变化时运行 `corepack pnpm build`
- 桌面端到端行为运行 `corepack pnpm test:electron-smoke`
- API/Postgres 持久化或认证变更运行 `corepack pnpm test:postgres-smoke`
- 试点服务栈/生命周期变更运行 `corepack pnpm test:docker-smoke`
- 全新部署、保留数据升级、升级失败恢复和有限应用回退运行 `corepack pnpm test:docker-lifecycle-smoke`
- 未签名桌面试点产物先运行 `corepack pnpm build:desktop-pilot`，再运行 `corepack pnpm test:desktop-pilot-smoke`

任何真实付费冒烟仍仅用于发布，并需单独明确授权费用。
