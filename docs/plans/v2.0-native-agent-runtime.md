## 交付规则

- 每个行为批次遵循先失败、再通过、再重构。
- 每个提交独立可撤销；下一批前保持分支验证通过。
- 不扩展到 V2.1 检索/记忆或 V2.2 多 Agent。
- 保留确定性工作流、Gate、策略、预算、桌面、团队与 GitHub 交付权限。
- 默认测试使用模拟决定、工具/MCP 样例及模拟/OpenCode 契约样例，不调用付费服务商。
- 团队投影不含原始提示词、源码、补丁、标准输出/错误、凭据或绝对路径。

<a id="protocol-defaults-and-hard-maxima"></a>

## 协议默认值与硬上限

策略或场景可降低默认值，渲染器/模型不能提高硬上限。

| 限额 | 默认 | 硬上限 |
| --- | ---: | ---: |
| Agent 步数 | 12 | 32 |
| 实际耗时 | 10 分钟 | 30 分钟 |
| 工具/MCP 调用 | 16 | 64 |
| 单个工具结果 | 64 KiB | 256 KiB |
| 轨迹事件安全元数据 | 16 KiB | 64 KiB |
| 检查点序列化安全状态 | 128 KiB | 512 KiB |
| 权限决定窗口 | 60 秒 | 5 分钟 |
| MCP 启动 | 10 秒 | 30 秒 |
| MCP 调用 | 30 秒 | 2 分钟 |

费用/Token 预算继续使用权威项目策略和已有 lead 批准规则。运行时增加已消费/剩余计数，不另建预算权威。

## 第 1 批：领域与确定性内核

结果：共享纯契约不执行 I/O，约束限额和状态转换。

失败测试：

- 拒绝畸形 ID/时间、未知事件/停止类型、无效限额、超大元数据、缺范围、能力摘要不匹配、序号缺口、过期检查点、终态继续、取消后迟到提交及预算/步数/截止时间越界。

- 添加版本化 V2.0 场景清单、解析器和指标累积器。

验证：

- 共享针对性测试、属性/边界矩阵、类型检查、完整单测和跨平台序列化。

提交边界：仅共享内核及场景契约。

## 第 3 批：原生工具注册表

结果：主进程显式注册的工具通过统一能力边界执行。

失败测试：

- 重复/未知工具、不支持的 JSON 模式、未知输入/输出字段、伪造/到期/错范围授权、权限拒绝/过期、调用数耗尽、超时、取消、超大结果、脱敏失败和取消后迟到结果。
- 跨组织/项目/用户/会话/本地项目授权绝不能执行。

最小实现：

- 不可变工具定义、编译模式验证器、主进程不透明 `ToolCapabilityGrant` 注册表、分派器、截止/取消处理、结果摘要/上限及本地审计。
- 工具限仓库相对路径列表/读取、受管工作区编辑、已保存测试执行和确定性场景评估，不向渲染器开放通用命令行。

验证：

- 共享注册表、主进程集成、真实临时工作树、Windows 路径、秘密/路径扫描和打包场景。

提交边界：仅原生工具执行。

<a id="slice-4--trusted-local-mcp"></a>

## 第 4 批：可信本地 MCP

结果：显式安装的本地 stdio MCP 服务加入同一工具契约。

失败测试：

- 证明团队 `McpServerDefinition.command` 与渲染器载荷不能到达进程启动。
- 拒绝未核验可执行文件、可变参数、继承秘密环境、错误身份、协议/版本不匹配、重复工具、无效模式、启动/调用超时、超大/畸形消息、取消、崩溃、禁用/修订安装、过期发现摘要和不确定非幂等重放。

最小实现：

- 持久化 `LocalMcpInstallation`，创建/修订/启用/删除仅由主进程执行。
- 实现 stdio 生命周期、有界握手/发现、模式转换/校验、环境变量名白名单（不继承父环境）、精确授权调用、审计、取消与关闭。
- 添加确定性 MCP 样例及场景；仍拒绝远程传输。

已实现边界：

- 桌面模式 20 拥有 `local_mcp_installations`；团队命令字段只作元数据，不是启动权限。
- 主进程启用时验证正式可执行文件及摘要，启动前和每次调用前重核精确安装；发现绑定协商能力摘要，仅元数据工具审计记录精确安装 ID/版本。
- 子环境始终含一个固定、非敏感隔离标记，避免 Windows 空环境块继承父环境；其他产品环境变量都必须在安装白名单内。跨平台测试单独列出 Node/libuv 在 Windows/macOS 必须加入的非敏感运行时变量。
- MCP 进程只在 Node `close` 事件（进程退出且 stdio 句柄关闭之后）视为关闭，以保证 Windows 取消及临时目录清理安全。
- 打包样例只用 stdio、显式环境白名单、有界消息/截止时间，接受一次 `scenario.evaluate`，冷重启零重复执行。

验证：

- 桌面模式/IPC、进程生命周期、环境泄露探测、重启/取消、打包 MCP 冒烟和跨平台源码检查。

提交边界：仅可信本地 MCP。

<a id="slice-5--governed-coding-executor"></a>

## 第 5 批：受治理编码执行器

结果：OpenCode 与测试样例实现同一执行器契约，不回退 1.x 编码行为。

失败测试：

- 能力协商、不可用/缺能力、无权限请求完成、重复权限、权限到期、取消/超时、清理失败、结构化结果与事件顺序。
- 映射现有 OpenCode 行为，不伪造其私有内部事件。

最小实现：

- 增加描述符、能力、请求、事件、句柄和终态契约。
- 用兼容执行器包装 `CodingEngineAdapter` 与 OpenCode，逐步迁移调用者并保留传输测试。
- 创建原生/OpenCode 事件族及终态对等样例。

已实现边界：

- 模型调用或工作区副作用前选定精确可用描述符及不可变能力，并在启动前持久化选择。
- 执行器只收主进程生成的无路径请求：范围 ID、权限版本、摘要、限额和能力引用；工作树路径留在私有 Electron 上下文。
- 兼容适配只输出可观察的启动/权限/证据事件，拒绝重复已决定权限，保留取消、超时、预算和清理语义。
- 无权限请求完成和权限继续两条路径收敛到统一终态，包含执行器身份、检查点、仓库相对路径、差异/测试证据引用、用量、停止原因和清理状态。

验证：

- 现有编码运行时/OpenCode 测试、新契约、类型检查、模拟编码演练、取消/清理冒烟；批次其余内容冻结后，单独显式运行一次仅发布时真实 OpenCode 探测。

提交边界：OpenCode 兼容与共同契约，尚无原生编码循环。

<a id="slice-6--narrow-native-coding-agent"></a>

## 第 6 批：有限范围原生编码 Agent

结果：DevFlow 运行时通过原生工具完成一次有界仓库修复。

失败测试：

- 无合格开发节点、缺 Gate/策略/预算、工作区不匹配、禁止路径、工具拒绝、测试失败、修复耗尽、取消、超时、步数/预算限制、编辑/测试之间重启及清理失败。
- 证明无法发布、合并、批准 Gate、执行任意命令、访问外部路径或第二工作区。

最小实现：

- 增加确定性决定服务与显式配置的有界模型服务。
- 只使用已注册原生工具，在受管工作树执行计划/读取/编辑/测试/评估/修复循环。
- 提供共同差异/测试证据/终态，保留编码任务说明、权限、预算和清理语义。

已实现边界：

- 主进程明确选择兼容、确定性原生或已配置有界模型原生执行。默认确定性路径无费用；模型路径要求权威预算批准、三次调用硬上限及精确服务商用量。
- 第一次模型决定选择一次仓库读取，其脱敏结果绑定到独立编辑决定，模型不能在观察前决定编辑。
- 原生执行器只读一个仓库相对源文件，请求一次获批工作树编辑，只执行已保存且可识别的测试，最多进行一次重新批准的修复。没有发布、合并、Gate、通用命令行、外部路径或第二工作区权限。
- 已批准决定和检查点从本地持久状态恢复，重启不调用模型或重复完成的写入/测试；测试执行不确定时拒绝继续。
- 权限前计划/读取/依赖准备时重启，将取消未完成运行时并终结外层编码运行，保留工作区供显式重试。
- 打包冒烟完成一次确定性修复，保存一次权限决定与六条精确工具审计，冷启动零重复工具效果。

验证：

- 版本化原生编码场景、每个检查点故障注入、执行器对等、Electron/打包冒烟、秘密/路径/源码扫描；有界真实模型证据可在默认 CI 外另行执行。

提交边界：有限范围原生编码 Agent。

<a id="slice-7--runtime-ux-and-team-projection"></a>

## 第 7 批：运行时界面与团队投影

结果：开发者和审查者理解进度与恢复，不因此获得新的修改权限。

失败测试：

- 严格渲染器 DTO、没有本地路径/源码/原始输出、过期动作拒绝、选错运行时、重复命令、乱序摘要、跨项目读取和乐观并发。
- 团队不能恢复运行时、注入工具结果、签发能力或推进工作流。

最小实现：

- 桌面运行时列表、详情、轨迹、限额、权限、取消/恢复及证据界面。
- 团队模式 16 脱敏摘要/审计、API/Postgres 路由/仓库、单调发件箱同步及 Web 只读管理投影。
- 完整轨迹/检查点留本地；团队只收稳定计数、状态和摘要。

已实现边界：

- 主进程严格投影只公开所选 Run/本地项目摘要、限额、计数、摘要值、安全事件类型与脱敏评估；源码、输出、检查点、范围元数据和绝对路径留主进程。
- 恢复/继续/取消使用精确版本/检查点乐观并发；过期选择拒绝，重复/乱序通知不能回退渲染器状态。
- 面板用于观察，可检查和继续已授权运行时，不能建立新权限、签发能力、注入工具结果或修改工作流/Gate。
- 打包探测证明一个运行时和一个原生编码运行冷重启后保留，工具效果零重复。
- 桌面模式 21 原子入队并合并精确、仅元数据的 `agent-runtime-summary` 操作，本地范围运行时状态从不上传。
- 团队模式 16 只保存 `agent_runtime_summaries` 及版本化 `agent_runtime_projection_audits`。严格 `/api/sync/agent-runtime-summary` 和种子/Postgres 实现拒绝跨项目、过期/同版本改写、终态修改及未知字段。
- Web 管理投影只读，仅显示状态、版本、安全计数和摘要，不能恢复、授权能力或推进工作流。

验证：

- 种子/Postgres 对等、v15→v16 数据保留、真实 PG 冒烟、渲染器/组件、发件箱重启、Docker 冒烟/生命周期和脱敏扫描。

提交边界：界面与脱敏协作投影。

<a id="slice-8--v20-evaluation-and-completion-gate"></a>

## 第 8 批：V2.0 评估与完成门禁

结果：路线图的完成声明由绑定候选的 V2.0 证据支撑。

失败测试：

- 评估器拒绝缺场景、错候选 SHA、数据集/契约版本变化、执行器对等不全、缺检查点/取消/限额证据、非零隔离泄露、意外付费调用、秘密/路径/源码或额外字段。

最小实现：

- 冻结版本化数据集，运行原生工具、MCP、检查点恢复、限额/取消、原生编码和 OpenCode 契约场景。
- 记录质量、费用、延迟、人工介入、恢复和隔离指标。
- 运行完整本地、Postgres、Docker 生命周期、Windows、macOS、Electron、打包、精确 SHA CI 及明确授权的真实服务商门禁。
- 只有全部通过才生成完成证据并更新路线图、README 和现行文档。

已实现边界：

- `scripts/fixtures/v2.0-agent-runtime-scenarios.json` 冻结 15 个确定性无费用场景，覆盖原生工具、原生/OpenCode 编码、本地 MCP、检查点恢复、取消、精确限额、畸形/超大结果、过期权限及租户/本地项目隔离。
- `scripts/v20-agent-runtime-evaluator.mjs` 严格验证数据集与完成记录，绑定候选/数据集 SHA 以及运行时/执行器/工具契约版本；缺失/失败场景、对等缺口、付费调用、泄露或未知字段均拒绝。

## 跨批次不变条件

- Agent/工具/MCP/执行器路径不能直接修改工作流或 Gate。
- 每个外部副作用都有显式权限、有界输入、截止/取消、审计和幂等/对账策略。
- 每次持久写入均版本化并使用乐观并发。
- 完整本地证据留桌面，团队只收严格脱敏摘要。
- 旧桌面/团队模式保留 1.x 数据，对未知 2.x 权限拒绝继续。
- 失败或不确定操作不能仅因客户端超时变成成功。
- 新文件纳入版本控制，每批以干净、已测试、已记录、已提交和已推送状态结束。
