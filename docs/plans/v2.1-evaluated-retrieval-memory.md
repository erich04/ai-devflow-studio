## 交付规则

- 一次完成一个可观察的先失败后通过流程，验证通过后再重构。
- 每个提交独立可撤销，下一批前保持分支通过。
- 保留 ADR 0007、确定性工作流/Gate 权限、V2.0 限额和桌面/团队存放边界。
- 向量化、排序、重排、记忆附着或模型使用前，先按范围及删除状态过滤。
- 默认 CI 确定且无费用；真实模型显式启用、有界且单独留证。
- 不扩展到 V2.2 多 Agent 协调。

<a id="slice-1--shared-retrieval-citation-and-evaluation-contracts"></a>

## 第 1 批：共享检索、引用和评估契约

结果：纯版本化契约不执行 I/O，拒绝畸形或越界数据。

先失败后通过的验证路径：

1. 解析精确范围请求，拒绝未知字段、错误限额和缺范围。
2. 接受有限词法/向量候选，拒绝重复、错范围/维度及旧哈希。
3. 生成精确知识引用，拒绝伪造或过期快照/片段身份。
4. 解析冻结语料并确定性计算词法基线指标。

验证：共享测试、语料解析、属性/边界、类型检查、完整单测及跨平台序列化。

提交边界：仅共享纯契约/评估器，无持久化或模型。

<a id="slice-2--deterministic-hybrid-retrieval"></a>

## 第 2 批：确定性混合检索

结果：本地无费用混合检索改善冻结语义案例，保留精确范围/引用行为。

先失败后通过的验证路径：

1. 确定性合并词法/样例向量候选，固定同分顺序。
2. 只重排已接纳范围，外部候选在评分前拒绝。
3. 刷新变更内容哈希，拒绝旧引用。
4. 冻结语料对比词法/混合指标，要求零隔离违规。

先使用确定性样例向量。后续模型适配器必须仍受凭据、预算、脱敏、截止时间和显式启用边界约束。

完成证据：43 项共享针对性测试及共享类型检查通过；冻结语料 Recall@K、nDCG@K、平均倒数排名均 `1.0`，相对词法的聚合提升 `0.5`，引用准确率/忠实度 `1.0`，隔离违规与付费调用为零。

提交边界：仅内存混合检索及评估行为。

<a id="slice-3--durable-local-retrieval-index"></a>

## 第 3 批：持久本地检索索引

结果：主进程拥有可恢复崩溃、限定项目的向量/索引状态。

先失败后通过的验证路径：

1. 保留数据，从桌面模式 21 迁移到 22，不伪造行。
2. 原子构建/激活精确快照，崩溃后旧快照仍为当前。
3. 源更新/删除在后续检索前使片段/向量/引用身份失效。
4. 损坏、维度/模型/范围不匹配时拒绝，重建保持有界。

本批不修改团队模式。

完成证据：21→22 迁移不伪造索引；持久化失败时原子替换保留旧快照；更新/删除移除旧当前身份；模型/维度错误、非有限值、超过 1024 片段和跨范围状态均拒绝。显式有界重建仅恢复派生索引，保留本地项目和 Run。最终通过 143 项本地存储及 43 项共享检索测试；仓库验证通过 192 文件/2729 测试、全部工作区类型检查、Next 生产构建、OpenCode 冒烟和跨平台桌面检查。

提交边界：桌面模式 22 与主进程索引持久化，不改团队模式或服务商。

<a id="slice-4--scoped-agent-memory-lifecycle"></a>

## 第 4 批：限定范围的记忆生命周期

结果：主进程记忆经过筛选、版本化、隔离、到期及安全删除。

先失败后通过的验证路径：

1. 从一个已接受可观察结果创建惰性候选。
2. 通过精确权限接纳，拒绝模型/渲染器/自行接纳及禁止内容。
3. 乐观并发修订，保留显式冲突和不可变历史。
4. 排序前排除跨范围、到期、墓碑和待清除行。
5. 删除、重启、清除派生索引，证明旧重放不能复活记忆。

完成证据：22→23 添加空惰性候选存储；23→24 添加修订/头/墓碑/派生索引/审计而不伪造生命周期；24→25 保留接纳历史并移除错误的“每候选仅一个修订”约束。主进程不透明能力控制接纳、修订、删除；精确头 CAS 保留不可变历史与显式冲突；返回内容前过滤范围、可见性、到期、墓碑及清除状态。派生索引清除前重启仍保留删除，旧授权修订不能复活。最终通过 152 项本地存储、48 项共享检索/记忆测试；活动批次推进到第 5 批后，仓库单测为 192 文件/2743 测试通过。

提交边界：仅本地记忆内核/存储/IPC，无团队投影。

<a id="slice-5--agent-runtime-and-desktop-ux"></a>

## 第 5 批：Agent 运行时与桌面界面

结果：知识引用和记忆修订进入有界上下文，来源可见。

先失败后通过的验证路径：

1. 附着精确当前引用/修订，轨迹仅记录白名单元数据。
2. 检查点后出现过期/删除/撤销，在下个外部动作前阻断继续。
3. 界面区分知识、工作记忆、候选、持久记忆、冲突、到期和删除；人工动作使用精确版本。
4. 打包重启保留已接受上下文，检索/模型/工具零重复。

已实现证据：桌面模式 25→26 保留迁移且新表为空；完整有界上下文仅由主进程持有。运行时创建和附着原子提交，冷启动重开同一附着，`contextDigest` 等于附着摘要。每个外部工具动作在调用前以及能力授权持久预留时，均重新核验当前快照/片段、记忆头/修订、墓碑、到期和团队配对。空检索结果也是有效有界上下文。

渲染器投影 v2 仅公开附着 ID、上下文/身份摘要、知识引用与持久记忆计数；源路径、正文、范围会话和完整附着留主进程。上下文矩阵通过 155 项本地存储、18 项桌面运行时、8 项共享契约、3 项渲染器投影、1 项访问、1 项控制台状态及 3 项面板测试。

桌面还把所选 Run 和持久运行时绑定到主进程推导的完整用户/会话/本地项目范围，在行访问前后重核正式 Run 和精确当前配对，提供主进程拥有的记忆生命周期访问。严格有界渲染器契约区分工作记忆、待接纳/已接纳候选、活动/冲突/到期/待清除/删除的持久记忆及精确修订/头版本。删除陈述、范围会话、不透明能力、权限摘要、原始输出和本地路径不进入渲染器。

人工接纳只针对所选运行时的待接纳候选，绑定渲染器观察到的候选 ID、内容与来源摘要。主进程推导固定的私有用户-项目权限，消费不透明能力，只返回刷新后的严格投影。人工修订只针对所选运行时的精确活动记忆，绑定当前修订/头版本、内容/来源摘要和有界替代陈述；主进程保留可见性、敏感性、保留期、到期及完整范围权限。

精确版本删除要求明确确认及相同版本/摘要边界。主进程构造人工权限，先保存墓碑再清除；重启可恢复精确待清除项，不重新创建删除权限。成功的已接受观察与惰性候选原子提交。打包桌面只通过严格 IPC 接纳修订 1、修改到 2、写墓碑并清除，再冷启动打开精确已删除生命周期；本地 MCP 和原生编码工具数保持精确，生命周期每次转换一条审计，派生索引为空，`memoryRestartDuplicateEffects` 为零。

生命周期矩阵通过 4 项共享投影、6 项主进程访问、6 项人工动作、7 项面板测试；仓库单测为 197 文件/2790 测试通过。

<a id="slice-6--redacted-team-projection"></a>

## 第 6 批：脱敏团队投影

结果：团队能看质量和生命周期元数据，不能读取或控制本地内容。

团队模式 17 添加空 `agent_memory_summaries` 与 `agent_memory_projection_audits`，保存有界引用 ID、生命周期/版本/计数和仅脱敏行，不含本地陈述、内容摘要、提示词、推理、凭据、路径、原始输出、本地项目或会话字段。模式 18 加入 `qualityVersion`，不改变内容边界；生命周期 `headVersion` 与已接受上下文质量独立推进，审计身份为精确 `(memoryId, headVersion, qualityVersion)`。全新及保留数据迁移不伪造记忆投影。

严格共享契约绑定团队项目、正式 Run/节点、源运行时、owner/候选身份、修订/头/生命周期、来源摘要、最多 64 个规范引用请求 ID 及有界质量计数。`acceptedContextCount` 不能大于 `retrievalCount`。被拒检索无持久记录，因此桌面只统计已持久接受到运行时上下文的检索，报告两个计数相等，不伪造尝试。新投影 `qualityVersion` 从 1 开始，推进至 `acceptedContextCount + 1`；保留版本 0 仅标记模式 17 的旧行，使其旧摘要可在升级首次同步时收敛。

桌面模式 27 保留模式 26 全部发件箱行，增加 `agent-memory-summary`。每次生命周期修改和接受上下文附着都原子合并一个仅元数据 ID 的发件箱操作。发送者从主进程状态重新推导当前投影，核对正式 Run/节点及当前配对，通过精确摘要端点上传。种子/Postgres 均执行固定范围、头/质量独立单调、组合审计身份幂等与禁止跨项目写入。Web 严格解析同一白名单，只显示引用数、已接受上下文数、修订、生命周期、可见性、敏感性和保留期。Web 始终只读，不能接纳/删除本地记忆、重建索引或恢复运行时。

先失败后通过的验证路径：

1. 模式 18 保留迁移不存本地内容，保留空 v17 投影，安装独立质量审计版本而不伪造投影。
2. 幂等同步精确单调白名单指标、引用 ID 和生命周期摘要。
3. 拒绝源/片段文本、提示词、推理、凭据、路径、原始输出和跨项目数据。
4. Web 只读；团队不能接纳/删除记忆、重建索引或恢复运行时。

四条路径及第 7 批候选门禁均完成。不可变证据绑定最终全仓库、真实 Postgres、Docker、跨平台、打包、脱敏及评估结果。
