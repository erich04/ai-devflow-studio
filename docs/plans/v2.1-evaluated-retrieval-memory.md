## Delivery Rules

- Use one observable RED → GREEN tracer at a time; refactor only when green.
- Keep each commit independently reversible and the branch green before the next slice.
- Preserve ADR 0007, deterministic Workflow/Gate authority, V2.0 Runtime bounds, and Desktop/Team
  placement.
- Scope and deletion filter before embedding, ranking, reranking, Memory attachment, or provider use.
- Default CI is deterministic/no-cost; real providers are opt-in, bounded, and separately evidenced.
- Do not widen V2.1 into V2.2 Multi-Agent coordination.

## Protocol Defaults And Hard Maxima

| Bound | Default | Hard maximum |
| --- | ---: | ---: |

Renderer/model input may lower a request limit but cannot raise these maxima or change scope.

## Slice 2 — Deterministic Hybrid Retrieval

Outcome: one local no-cost hybrid retriever improves the frozen semantic cases and preserves exact
scope/citation behavior.

RED → GREEN tracers:

1. Merge lexical and fixture-vector candidates with deterministic tie breaks.
2. Rerank only the admitted scope; a foreign candidate is rejected before scoring.
3. Refresh changed content hashes and reject stale citations.
4. Compare lexical and hybrid metrics on the frozen corpus with zero isolation violations.

Use deterministic fixture embeddings first. A provider adapter may follow only behind the existing
credential, budget, redaction, deadline, and explicit opt-in boundary.

Completion evidence: 43 focused shared tests and shared typecheck pass. On the frozen corpus,
Recall@K, nDCG@K, and mean reciprocal rank all reached `1.0`; aggregate improvement over lexical was
`0.5`; citation precision and faithfulness were `1.0`; isolation violations and paid-provider calls
were zero.

Commit boundary: in-memory hybrid retrieval and evaluator behavior only.

## Slice 4 — Scoped Agent Memory Lifecycle

Outcome: main-owned Memory is curated, versioned, isolated, expiring, and deletion-safe.

RED → GREEN tracers:

1. Create an inert Memory Candidate from one accepted observable result.
2. Promote through exact authority; reject model/renderer/self-promotion and forbidden content.
3. Revise with optimistic concurrency; preserve explicit conflicts and immutable history.
4. Exclude cross-scope/expired/tombstoned/purge-pending rows before ranking.
5. Delete, restart, purge derived index state, and prove old replay cannot resurrect Memory.

Completion evidence: Desktop schema 22 → 23 added empty inert candidate storage, schema 23 → 24
added revision/head/tombstone/derived-index/audit storage without fabricated lifecycle rows, and
schema 24 → 25 retained promotion history while removing the invalid one-revision-per-candidate
constraint. Main-owned opaque capabilities now gate promotion, revision, and deletion; exact head
CAS preserves immutable history and explicit conflicts; retrieval filters scope, visibility, expiry,
tombstones, and purge state before returning content; and deletion survives restart before derived
index purge while old authorized revisions cannot resurrect it. The final focused matrix passed 152
focused local-store tests and 48 focused shared retrieval/Memory tests. Repository unit verification
passed 192 test files and 2743 tests after the active-Slice document contracts advanced to Slice 5.

Commit boundary: local Memory kernel/store/IPC only; no Team projection.

## Slice 5 — Agent Runtime And Desktop UX

Outcome: Knowledge Citations and Memory revisions enter bounded Context with visible provenance.

RED → GREEN tracers:

1. Attach exact current citations/revisions and record only allowlisted trajectory metadata.
2. Stale/delete/revoke after checkpoint fences continuation before another external action.
3. UI distinguishes Knowledge, Working Memory, Candidate, Durable Memory, conflict, expiry, and

Current implementation evidence: Desktop schema 25 → 26 adds an empty retained migration and a

reservation. Empty retrieval results remain valid bounded Context. Renderer projection v2 exposes
only the attachment ID, Context/identity digests, and Knowledge Citation and Durable Memory counts;
source paths, bodies, scope sessions, and the full attachment remain in Electron main. The focused
matrix passes 154 local-store tests, 18 Desktop Runtime tests, 8 shared Context contract tests, 3
renderer-projection tests, 1 renderer-access test, 1 console-state test, and 3 Runtime-panel tests.
Repository unit verification passes 193 test files and 2757 tests, all workspace type checks, the
Next production build, and the OpenCode smoke type boundary.
