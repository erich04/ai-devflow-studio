# DevFlow Studio 产品定义

本目录是 DevFlow Studio 产品定义的阅读入口。各类文档按职责分别维护：

- `docs/plans/`：实现计划与里程碑执行。
- `docs/guides/`：演练与用户操作指南。
- `docs/adr/`：架构决策。
- `docs/engineering/`：测试、冒烟验证和工程过程记录。
- `docs/roadmap.md`：里程碑状态与后续规划。

本目录用于回答以下产品问题：

- 我们在构建什么产品？
- 谁会使用它？
- 它解决什么问题？
- 核心业务流程是什么？
- 哪些能力属于产品范围，哪些不属于？
- 哪些面向用户的概念需要跨版本保持稳定？
