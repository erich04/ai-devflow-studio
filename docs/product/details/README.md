# DevFlow Studio 产品细节

本目录按主题拆分产品细节。在重新设计界面、修改流程行为或判断某项能力是否属于产品范围之前，应先阅读对应文档。

<a id="product-promise"></a>

## 产品承诺

DevFlow Studio 将 AI 辅助软件开发组织为可评审的交付流程。开发者从原始需求出发，在本地开展 AI 辅助工作、收集证据、通过人工门禁，再将安全摘要同步给团队；无需向团队服务上传原始仓库内容或模型提供方密钥。

产品服务于小型工程团队，核心是工作流和证据体系，对话是其中的交互方式。
