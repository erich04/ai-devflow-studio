# V2.1 可评估检索与记忆需求

状态：已完成——绑定候选的完成门禁通过

日期：2026-08-13

路线图位置：V2.0 之后的第二个 2.x 里程碑，已完成

<a id="summary"></a>

## 概要

V2.1 使 DevFlow 检索效果可测量，并为有界 Agent 运行时提供限定范围、可审查的记忆。新增混合检索、确定性重排、精确引用、版本化评估语料及受治理记忆生命周期，同时保留本地仓库权威、ADR 0007 和确定性工作流/Gate 边界。

<a id="problem"></a>

## 问题

词法检索确定且可解释，但难以召回词汇重合少的语义匹配。检查点能精确继续执行，却不能在后续会话中提供受治理回忆。未经契约约束就加入向量或保存模型输出，会带来质量不可测、伪造引用、过期来源、租户泄露及无法删除的影子状态。

<a id="users-and-jobs"></a>

## 用户与任务

<a id="developer"></a>

### 开发者

- 检索最相关的当前仓库知识，获得精确、可检查的引用。
- 看到记忆何时影响 Agent，以及其范围、版本、来源和到期时间。
- 接纳、修订或删除符合条件的记忆，不向团队暴露源码或凭据。

<a id="lead-or-reviewer"></a>

### 负责人或审查者

- 使用固定指标和冻结语料比较混合检索与词法基线。
- 核验引用片段支持有界陈述，且检索仍不等于治理证据。
- 审计记忆接纳/删除和脱敏团队投影，无需读取私有本地数据。

<a id="local-operator"></a>

### 本地操作员

- 确定性重建本地索引，诊断过期/损坏条目，验证删除与清除。
- 显式启用付费服务商场景，不纳入默认 CI，也不泄露秘密。

<a id="product-principles"></a>

## 产品原则

1. 测量检索改进，不能把有向量存储视为产品完成。
2. 引用身份与范围具有权威，相似度分数没有。
3. 记忆经过筛选、版本化、限定范围、可到期和可删除，不等于聊天历史。
4. 检索与记忆属于上下文，不是工作流状态或治理证据。
5. 完整仓库内容和本地记忆默认留在 Electron 主进程。
6. 范围过滤与删除生效必须早于排序和模型使用。
7. 默认验证确定、版本化且无费用。

<a id="functional-requirements"></a>

## 功能要求

<a id="fr1--versioned-retrieval-request-and-result"></a>

### FR1：版本化检索请求与结果

- 请求绑定精确组织/项目/用户/会话、Run/节点、本地项目、知识快照哈希、分类/标签、TopK、分数边界和检索契约版本。
- 返回有界命中，包含精确文档/片段/内容/快照身份、策略链、排序、有限分数和原因元数据。
- 拒绝未知字段、非规范 ID/时间、无效维度、过期快照、重复身份和跨范围结果。

<a id="fr2--hybrid-retrieval-and-reranking"></a>

### FR2：混合检索与重排

- 保留词法检索作为稳定基线及回退。
- 只从预先过滤的精确范围接纳向量候选，确定性合并并只重排已接纳集合。
- 向量模型和排序身份版本化；同分排序不能依赖 Map/数据库顺序。
- 文本离开本地前，外部向量化/重排必须有显式有界服务商权限及预算。
- 范围、预算与文本传输权限通过前，不解析任何服务商凭据。

<a id="fr3--exact-citation"></a>

### FR3：精确引用

- 引用绑定文档、片段、来源相对路径、标题、内容哈希、快照哈希、策略链及检索名次。
- 拒绝过期、删除、不可访问、伪造、不匹配或不支持陈述的引用。
- 分别记录引用准确率和忠实度；存在引用不等于引用正确。
- 绝不自动把引用或命中升格为治理证据。

<a id="fr4--memory-candidate-and-promotion"></a>

### FR4：记忆候选与接纳

- 运行时观察可生成有界候选，绑定精确范围及来源摘要。
- 候选保持惰性，直到主进程策略/操作者权限将其接纳。
- 接纳生成不可变修订版 1，包含可见性、敏感性、保留期、到期和审计。
- 隐藏推理、原始提示词、凭据、源码、补丁、标准输出/错误及绝对路径绝不成为记忆或团队投影字段。

<a id="fr5--memory-revision-conflict-expiry-and-deletion"></a>

### FR5：记忆修订、冲突、到期与删除

- 更新要求精确乐观并发，创建不可变的替代修订版。
- 冲突显式保留，模型或“最后写入胜出”时间戳不能静默决定权威。
- 到期或待清除记忆在排序前排除。
- 删除单调、先写墓碑、可重启恢复，清除派生索引；旧重放或团队同步不能撤销删除。

<a id="fr6--isolation-and-placement"></a>

### FR6：隔离与存放位置

- 检索前执行组织/项目/用户/会话/本地项目/可见性交集过滤。
- 跨租户请求既不泄露内容，也不泄露存在性、数量或时间差异。
- 桌面模式 22 是首批本地持久化；本地语义通过后，团队模式 18 才存仅元数据的脱敏投影。生命周期 `headVersion` 与已接受上下文 `qualityVersion` 独立推进；桌面模式 27 只增加仅含 ID 的元数据发件箱，不伪造本地或团队记忆。
- API/Postgres 不能恢复本地检索、接纳完整记忆或索取仓库内容。

<a id="fr7--runtime-and-ux-integration"></a>

### FR7：运行时与界面集成

- Agent 上下文分别标记知识和记忆，在可观察轨迹记录精确已接受引用/记忆修订身份。
- 引用或记忆过期/删除后，下次继续执行必须在任何工具、模型、MCP 或编码执行器动作前失效。
- 桌面显示来源、策略、分数/名次、范围、版本、冲突、到期和删除状态；团队/Web 只收白名单脱敏摘要。
- 团队/Web 严格解析生命周期/版本/来源/引用 ID 及持久化已接受上下文计数，不提供接纳、修订、删除、清除、重建或恢复运行时命令。

<a id="evaluation-contract"></a>

## 评估契约

冻结语料为 `scripts/fixtures/v2.1-retrieval-memory-evaluation.json`，仅含可审查合成内容及精确预期/禁止身份。评估器比较词法基线与混合候选的 Recall@K、nDCG@K、平均倒数排名、引用准确率、引用忠实度、延迟、记忆任务质量和隔离违规。

完成门禁要求：

- 混合检索相对词法基线达到冻结的聚合质量改进阈值；
- 引用准确率/忠实度达到冻结下限，伪造/过期引用为零；
- 记忆在不增加人工介入下改善选定任务结果；
- 跨租户、删除、到期、旧修订及禁止复活场景零泄露；
- 默认评估器不调用付费模型，记录候选/语料/契约摘要；
- 本地、保留数据迁移、真实 Postgres、Docker、打包、Windows、macOS、脱敏和直接子提交完成证据门禁均通过。

<a id="non-goals"></a>

## 非目标

- V2.2 多 Agent 调度者/专长角色协调或托管执行租户。
- 公共 SaaS、托管向量基础设施、计费、企业 SSO 或托管模型秘密。
- 替换可审查 Git Markdown 作为知识事实来源。
- 将记忆、检索分数、引用或模型置信度当作工作流/Gate 权限。
- 任意上传文本、隐式同步仓库或隐藏聊天历史记忆。
- 在行为/评估批次证明必要前选定永久向量数据库。
