# Codex 对顾问意见的处理

Cursor 会话：`4b26bf07-d457-42bd-9acd-40e99d7fbe71`。模型：`grok-4.7-xhigh`，只读 Ask。首轮完成源码核对并产生同目录 `attempt1.review.md`；未提供符合约定的最终 JSON，自动格式重试返回模型不可用。没有改用其他模型。以下依据已收到的文字意见及 Codex 自行核对的源码，结构化重试失败不构成实施门禁。

| 意见 | 决定与理由 |
|---|---|
| 配对正式模型流程与 V2 的未配对限制冲突 | 采纳。配对后需重新明确授权本机私有知识；记录组织、团队项目、本地项目、用户，并补入认证账号身份。Token 轮换不撤销；身份变化撤销并清理。 |
| 不新增虚构的组织知识外发策略 | 采纳。现有团队策略只治理 Gate/模型预算；单独的本地授权说明 Hindsight 上传与摘录进入模型两条数据路径。不扩大团队共享范围。 |
| 配对知识不启用正式记忆投影 | 采纳。拒绝配对配置的 `includeMemories: true`；保留原记忆范围及影子召回。 |
| 全部实际模型入口与恢复共享来源回执 | 采纳。Stage、Review、Coding 共用宿主检索与当前性校验；OpenCode 每轮经代理核验；Native 修复复用原简报，失效需新运行。 |
| 检索段先于 Memory/Gate/修订输入裁减，预算与回执一致 | 采纳保护原则。真实验证发现仅使用剩余预算会使编码检索没有空间，因此最终为 Coding 尽力预留最多 4 KiB，压缩可选叙述；已批准输入、Memory、Gate 和项目指令仍优先，装不下时省略检索。回执只记录实际发出的原文。设计修订现有顺序与正文保留。 |
| 测试命令、交付包、验收包不接线 | 部分采纳。它们不新增模型调用。测试命令另记录知识来源并在执行前后核验，回应用户选择的测试阶段接入；命令内容仍来自项目配置。交付/验收使用既有 Agent Review 入口；不伪造发布或审批完成。 |
| API 审查不读取桌面私有投影，讨论保持工具检索 | 采纳。桌面本机知识不接入服务器检索；讨论不重复自动注入。同步摘要须剥离新增私有检索回执。 |
| 本轮抽取和开发模型须共用原累计人民币 5 元上限 | 采纳。旧账本关闭并保持原 hash；新账本仅允许剩余 ¥4.949398，所有付费请求共用同一网关。团队预算治理仍正常执行。 |
| 只能保留新账本 5 元字段并用历史结转占额 | 不采纳具体实现。改为只允许调小的严格账本上限，运行配置必须匹配已持久化上限，初始化不可覆盖。更直接地防止重启扩大额度；报告另记录旧支出及 hash，累计总额相同。 |
| 排序与答案质量分开，不能掩盖英文检索问题 | 采纳。固定题库与验收答案不进入知识目录；报告实际检索观察及未完成项，不把合成协议测试当真实质量。 |

上述是实施决定，实际验证结果另见本轮验证记录。Cursor 没有审批权，最终改动和测试结论由 Codex 负责。
