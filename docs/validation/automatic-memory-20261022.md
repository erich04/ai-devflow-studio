## 复审修正

- 手动保存已知语义槽也检查冲突，不能并存两份未经确认的矛盾偏好。
- 对相同文本点击固定会升级已有 Memory；自动重复与普通重复不会续期。
- 确认替换只退役指定旧条目，不执行整事件遗忘；同一旧事件的其他固定经验保持有效。
- Chat 最终发送前再次验证当前用户、配对、修订、删除与有效期；失效时不发送旧正文。
- 过期远端暂存清理不撤销本地固定经验，迟到远端结果不重新导入。
