## 诊断开销实测

仅在本机、合成数据、无网络模型下测量，不是跨机器性能承诺：

| 内容 | 样本 | 中位数 | P95 | 大小 |
| --- | ---: | ---: | ---: | ---: |
| 导出 200 条白名单诊断 | 100 次 | 3.73 ms | 5.15 ms | 95,599 bytes |
| SQLite 保存 200 条基础调用记录 | 20 次，预热 5 次 | 13.63 ms | 22.93 ms | 数据库 1,138,688 bytes |
| 同样记录附加逐次诊断 | 20 次，预热 5 次 | 15.92 ms | 25.97 ms | 数据库 1,277,952 bytes |

此样本附加诊断占 139,264 bytes，保存中位数增加约 2.29 ms；导出小于 512 KiB 上限。测量包含 LocalStore 正常持久化路径，没有将导出耗时冒充写盘耗时。原始数字为 `diagnostic-benchmark.json` 与 `diagnostic-write-benchmark.json`。不增加逐 token 诊断落盘。
