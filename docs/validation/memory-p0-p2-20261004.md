固定回归场景覆盖相关/无关记忆、跨用户/项目范围、冲突与旧版本、删除/过期、中文长度、原始关键条件、已回答问题与已保存草稿、多工具结果、重复压缩和重启。原 V2.1 冻结语料评估在 `1a80263` 通过：语料 SHA-256 `052b6ea8f2fe06ed4f2614b00b102d6b05e147b790196687bf5d7f299d3b3008`。该小语料的合成质量指标只说明冻结契约，不证明本次 BM25 或长期记忆提高真实复杂任务完成率。

## 发现、修复与复核

Standards 轴发现来源摘要字段损坏导致同 ID 回执被跳过，以及 cancelled 后崩溃遗留工具请求；分别补失败回归并修复。另采纳显示阈值来自共享预算的建议。定向复核已关闭两项发现，无剩余阻塞。

Spec 轴发现格式重试指令未计入预算，以及损坏链元数据阻塞会话保存；分别补失败回归并修复。原复现的 47,999 Token 首请求可发送，超限重试在发送前拒绝；缩短输入后两次请求为 47,867 / 47,991，回执一致。损坏链后的显式重试完成至 idle 且保留原文。追加的重复工具事件落盘断言也已通过；定向复核无剩余阻塞。

开发中的非通过记录均保留：首次全量 verify 因新测试错误使用 `runtime: 'local'` 而 exit 2，改为 `electron`；下一轮 4,745 项通过、1 项 README 旧边界断言失败而 exit 1，更新为当前受限学习契约。Native Token 缩窗曾遇到只超 Token、不超字符时的非递减循环，改为单调缩小后通过长中文失败位置测试。模拟保存失败的测试曾因在持久队列内递归调用 spy 阻塞，改为公共存储适配器后通过，未放宽全局超时。

确定性 OpenCode 的初始未定价 fixture 被预算拒绝，改用可由仓库价格表计价的合成模型并显式限制输出，没有绕过预算。报告旧费用字段的失败断言修复为按逐调用账本汇总。专用费用库首次 seed 因未设置 `DEVFLOW_ENABLE_DEMO_DATA=true` 被安全拒绝；随后显式迁移/启用夹具并通过，没有使用应用数据库。
