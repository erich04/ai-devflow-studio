## 用户数据保护与真实流程限制

升级尝试前使用 SQLite 原生备份保存用户数据库和配置。对比升级前后 Run、节点、产物、审批、事件及聊天消息，没有修改已保存业务进度或替用户批准 Gate。原应用已恢复启动。当前用户案例仍是任务清单完成状态筛选，设计已生成，停在方案评审 Gate；没有伪造开发、测试、PR 或业务验收结果。

候选包与恢复的原包读取系统凭据均返回 `errSecAuthFailed (-25293)`；桌面控制确认 Mac 处于锁屏状态。不能仅凭此认定凭据损坏，也未清空凭据、数据库或工作流。真实 Provider 全流程需在用户解锁后继续。系统当前没有可用 Developer ID 签名身份，#135 的独立签名安装验收仍缺失。
