# 项目记忆真实模型验证：第五期全链路（2026-10-29）

对应 [ADR 0030](../adr/0030-hindsight-project-memory.md) 第五期，接续 [2026-10-28 的验证](project-memory-live-20261028.md)。用户授权的总预算为 3 美元，累计记在 `out/project-memory-validation/ledger.json`（不提交）。

## 方法

`scripts/project-memory-live-validation.mts`，合成数据，不读业务项目，固定版本 Hindsight 1.0.0（本仓库 Compose，Docker Desktop，macOS），结束后删除测试 bank。

- **抽取**：用 DevFlow 自己的采集函数构造 8 个文档：旧版本地记忆（`source:legacy`，两条）、三段讨论（第二段把撤销窗口从 5 秒改为 10 秒，第三段把答复语言从中文改为英文）、一次失败和一次修复成功的编码记录、一份已批准的设计、一天的 Git 提交信息（`source:commit`）。经发件队列写入 Hindsight，抽取和归纳经 DevFlow 中继调用 DeepSeek `deepseek-v4-flash`（thinking 关闭）。
- **召回**：6 个问题，按编码（8 条）和讨论（4 条）两种预算检查真正会送进提示的内容，新增旧版记忆和提交信息两个问题。
- **知识页**：由后台 worker 创建并写出四个知识页（没有在脚本里直接刷新），检查每页包含该写的内容。
- **讨论**：用 `WorkbenchConversationService` 和真实 DeepSeek `deepseek-flash`（thinking low）各开一次原生 v2 和结构化 JSON 讨论，用中文问「用两句话解释什么是回归测试」，检查回答是否按记忆中较新的偏好用英文。
- 预算：中继和讨论共用脚本内的硬上限，按最坏情况预留、按实际 usage 结算，未结算的预留按已花费计。

三次合计 $0.1269，累计 $0.1364，占 3 美元预算的 4.5%。最后一次：8 个文档全部写入，Hindsight 得到 33 条记忆（13 条 observation），中继 29 次调用全部成功。

- **抽取与归纳**：两次决定变更都被正确合并，例如「用户要求从现在起用英文回答，代码注释也写英文；此前用中文回答的要求作废」。8 个文档约 11 次调用、约 1 美分。
- **召回**：6 个问题在编码和讨论两种预算内全部命中，包括旧版记忆（`dist/` 不提交）和提交信息（超过 500 条时改用虚拟滚动）。
- **知识页**：四页都写出了带时间线和依据的中文内容，例如用户偏好页写明「当前有效的要求是用英文回答……2026-10-28 的“用中文回答”已被用户本人明确作废」，问题页区分 `HOST_VERIFIED` 结果和 Agent 的说法。每页一次约 0.8 美分，是抽取的 8 倍左右。
- **讨论**：修复后两种协议都用英文回答，例如「Regression testing is the practice of re-running existing tests after a change……」。

## 发现的问题和处理

1. **记忆里的语言偏好没有生效。** 第一次运行中，记忆已经送到（回执 4 条，其中有改用英文的 observation），两种讨论仍用中文回答。原因有两个：原生对话的系统提示开头写死了「使用中文」；混在背景记忆里的偏好被模型当作资料，不当作要求。2026-10-22 的旧链路遇到过同样的问题，当时靠宿主核验的结构化设置放在包尾解决。现在改为：讨论每一步另做一次小召回，专门找答复语言、详略类的记忆（与固定查询至少共享一个词），最多 2 条放在请求末尾的 `communicationPreferences`，紧挨当前请求；系统提示要求按其中最新的偏好作答，当前请求优先；去掉原生提示里的「使用中文」，没有偏好时仍默认中文。这些记忆和背景记忆一样进回执，发送前一样检查是否被修改或删除。
2. **知识页可能长时间是空的。** 前两次运行中，归纳完成几分钟后四个页面仍为空，只能手动刷新。页面在 bank 为空时创建，之后的自动改写受最小间隔限制，没有在验证窗口内发生（推测创建时那次跳过的刷新也计入了间隔，未从 Hindsight 源码确认）。现在 worker 发现「页面为空，且之后有新写入、编辑或删除」时请求 Hindsight 写一次：同一页每 10 分钟最多请求一次，失败后等 1 小时，有来源正在删除时先等删除完成。第三次运行中四页在开始后约 40–80 秒写出。
3. **知识页改写比抽取贵。** 每页一次约 0.8 美分。自动改写的最小间隔从 1 小时改为 6 小时；用户可随时「立即整理」。

## 未验证

- 团队配对、真实团队预算的预留和结算（本次用脚本内预算）；完整桌面界面流程。
- 长期使用后的召回和知识页质量；Git 提交信息只验证了一天的合成提交。
- 讨论中的偏好召回依赖固定查询词，答复顺序类偏好（如「先说行为变化再说测试」）没有覆盖到包尾，仍可经背景记忆送达。
