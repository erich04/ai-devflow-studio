# 中文任务清单

一个从零实现的纯前端中文任务清单单页应用，使用原生 HTML / CSS / JavaScript，不引入任何前端框架，也没有任何第三方运行或测试依赖。

## 功能

- 新增任务：输入任务内容后点击「添加」或按回车即可新增。
- 完成切换：勾选复选框将任务标记为已完成，再次勾选可取消完成。
- 删除任务：点击「删除」直接移除单条任务，无需二次确认。
- 本地持久化：任务保存在浏览器 `localStorage`，刷新页面后内容、完成状态与删除结果均保持不变。
- 输入校验：去除首尾空白后为空或超过 200 个字符时不新增，并给出中文提示。
- 中文界面：包含中文空状态提示与输入提示，无未翻译的英文占位文案。

## 环境要求

- Node.js 18 或更高版本（需要内置的 `node:test` 与全局 `fetch`）。
- 现代桌面浏览器，验收目标为桌面 Chrome。

## 安装说明

本项目**无第三方依赖**，无需执行 `npm install`。仓库中不包含 `dependencies` 或 `devDependencies`。

## 启动应用

```bash
npm start
```

启动后访问：<http://127.0.0.1:5173>

如需修改端口，可通过 `PORT` 环境变量覆盖：

```bash
PORT=8080 npm start
```

此时访问地址为 <http://127.0.0.1:8080>。

## 运行测试

```bash
npm test
```

该命令等价于 `node --test`，使用 Node 内置的 `node:test` 与 `node:assert`，零第三方依赖。测试失败时进程返回非零退出码。

### 测试范围

- 任务逻辑（`src/store.js`，通过可注入的内存 Storage 验证）：
  - 新增任务，默认未完成；
  - 按创建顺序排列；
  - 空白输入的拒绝；
  - 200 / 201 字符边界与首尾空白 trim 后的校验；
  - 完成状态的双向切换；
  - 删除单条任务且其余顺序不变；
  - 序列化与重新载入后内容、完成状态、删除结果保持一致；
  - 非法 JSON、非数组、非法数据项的容错；
  - 不存在的任务 id；
  - 存储读写抛异常时的内存退化。
- 开发服务器（`scripts/dev-server.js`）：
  - `/` 返回首页 HTML；
  - `.js` 以 `text/javascript` 返回以支持 ES module；
  - 路径穿越请求与未命中路径返回 404。

> 说明：自动化测试覆盖业务逻辑与序列化/重新载入，不等价于真实浏览器刷新。真实刷新持久化由验收者在桌面 Chrome 中手工操作确认。

## 数据存储

任务数据保存在浏览器 `localStorage` 的 `tasklist.tasks.v1` 键下，值为 JSON 数组，元素形如：

```json
{ "id": "…", "text": "写周报", "done": false, "createdAt": 0 }
```

数组顺序即任务创建顺序。每次新增、切换完成或删除后立即写入存储。

## 字符计数口径

任务长度按去除首尾空白后的 **Unicode 码点**（`Array.from(text).length`）计，上限为 200。因此单个 emoji 等代理对字符按 1 个字符计算。

## 已知限制

- 仅以桌面 Chrome 作为验收目标，其他浏览器可能行为不同。
- `localStorage` 在隐私模式、被禁用或容量受限时不可用；此时应用会退化为内存存储并在页面提示「当前浏览器无法保存数据，刷新后内容会丢失」，页面仍可使用，但刷新后内容不会保留。
- 不包含后端服务、账户体系或跨设备同步。
- 不支持任务编辑、排序、优先级、截止日期、标签或提醒等扩展功能。
- 不包含国际化/多语言切换，界面仅中文。
