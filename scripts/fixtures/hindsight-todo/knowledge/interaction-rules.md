# 清理交互与反馈规范

本文件是 Hindsight 验证的合成需求规范，版本 ui-v1。

模块：任务界面。规则名称：清理按钮与反馈。

在清单下方显示“清除已完成”按钮。只要存在已完成项就可用；空清单或所有任务未完成时禁用。勾选和取消完成后应立即更新按钮状态。

点击后直接执行，当前需求不增加确认弹窗或撤销。成功反馈为“已清除 N 项”，N 为实际删除数量。清空后沿用原有空状态，不额外创建另一套空列表页面。

中文输入、回车提交、新增、勾选和取消完成、单条删除必须保持原有行为。按钮需要有可读的中文名称并支持键盘操作；不要把原始任务文本作为 HTML 插入。
